TASK
Reduce SwitchControl telemetry CPU usage further without removing real telemetry.

PROBLEM
The user issue came from version 1.0.1, but current 1.0.6 telemetry can still be lighter. Current code still polls frontend every 2s even when backend low-end mode uses 6s, renders duplicate glow chart lines, and getSnapshot can force extra tick runs.

GOAL
Lower idle CPU usage, especially on weak PCs, without fake data and without breaking the LiveGraph.

IMPLEMENTATION

1. Stop getSnapshot from forcing full heavy tick
File: server/lib/telemetry.ts

Current:
if cached snapshot is older than 4000ms, getSnapshot calls tick().

Change:
getSnapshot must not run full tick. It should return cachedSnapshot if present, otherwise getCachedSnapshot(). Do not bypass scheduler.

2. Add scheduler interval to stats
File: server/lib/telemetry.ts

Add intervalMs to SchedulerStats:
intervalMs: lowEndMode ? POLL_LOW_END_MS : POLL_BASE_MS

3. Make LiveGraph polling adaptive
File: client/src/components/LiveGraph.tsx

Current:
setInterval(fetchTelemetry, 2000)

Change:
Use low-end detection:
const isLowEndClient = latest?.coreCount <= 4 || latest?.ramTotalGb <= 4;
const graphPollMs = isLowEndClient ? 6000 : 2000;

When expanded:
const graphPollMs = isLowEndClient ? 4000 : 2000;

Restart interval when graphPollMs changes.

4. Disable duplicate glow lines on weak PCs
File: LiveGraph.tsx

Add:
const isLowEndClient = latest?.coreCount <= 4 || latest?.ramTotalGb <= 4;
const showGlowLines = !isLowEndClient && !expanded;

Wrap every thick glow Line with showGlowLines.
Keep only the thin real line on weak PCs.

5. Reduce graph history on weak PCs
Current:
return updated.length > 60 ? updated.slice(-60) : updated;

Change:
const maxPoints = isLowEndClient ? 30 : 60;
return updated.length > maxPoints ? updated.slice(-maxPoints) : updated;

6. Strengthen RAM/GPU visual separation
Replace computeDisplayOffset with stronger visual offset:
if RAM and GPU are within 8%, separate them by at least 8 visual points.
Tooltip must still show true ram and true gpuLoad.

7. Throttle over-budget logs
File: server/lib/telemetry.ts

Do not console.log every skipped tick. Log once every 30 seconds max.

8. Optional network reduction
If network graph is disabled, do not run networkStats every tick. Run it every 6 to 10 seconds or only when net metric is enabled.

CHECKLIST
- No extra tick() from getSnapshot.
- Frontend does not poll faster than backend low-end mode.
- Weak PC graph uses 30 points.
- Weak PC graph renders no glow duplicate lines.
- RAM and GPU no longer overlap.
- Tooltip still shows true values.
- Logs do not spam when over budget.
- Idle CPU usage is lower than current 1.0.6.
