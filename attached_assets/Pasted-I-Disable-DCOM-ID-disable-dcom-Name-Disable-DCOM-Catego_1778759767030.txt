I. Disable DCOM

ID: disable-dcom
Name: Disable DCOM
Category: Advanced System
Risk: Risky
Recommended: No
Admin: Yes
Confirmation required: Yes

Registry:
HKLM\SOFTWARE\Microsoft\Ole

Apply:
EnableDCOM = "N"

Revert:
Restore baseline.
If no baseline existed, set EnableDCOM = "Y".

Check:
EnableDCOM equals "N".

Hard warning:
Can break Windows components, enterprise apps, remote COM features, and some installers. Must require confirmation before applying.

Never include in Apply Recommended.

2. Do NOT add unsafe competitor tweaks

Do not add:
- Disable DEP/NX
- Enable Intel TSX
- Disable VPN
- generic Disable WiFi as recommended
- generic Disable audio services
- microphone privacy disabling
- Windows Voice Clarity disabling
- audio enhancement disabling

Reason:
These can break security, networking, voice chat, Discord, Fortnite voice, or cloud auth.

If WiFi already exists, keep it Risky and warning-gated.
