TASK: Replace generic debloater app placeholders with real installed application icons

PROBLEM:
The Installed Apps section in the Debloater page currently uses generic cyan placeholder visuals instead of actual application icons/logos.

This makes the app look unfinished and unprofessional compared to native Windows utilities.

GOAL:
Display real application icons for installed software using Windows metadata and executable icon extraction.

IMPLEMENTATION:

1. Extend installed-app scanner backend to return:
   
   - DisplayIcon
   - InstallLocation
   - executable path
   - uninstall string
   - app type (Win32/UWP)

2. Primary icon source:
   Registry:
   HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall
   HKCU equivalents
   
   Read:
   
   - DisplayIcon
   - DisplayName
   - InstallLocation

3. If DisplayIcon exists:
   
   - resolve environment variables
   - resolve quoted paths
   - normalize ",0" icon index suffixes

4. Extract actual EXE icons:
   
   - use Electron nativeImage
   - or Windows shell extraction
   - cache extracted PNGs locally

5. Support Microsoft Store / UWP apps:
   
   - parse Get-AppxPackage
   - locate logo assets
   - extract Square44x44Logo or equivalent

6. Add icon cache system:
   Example:
   %APPDATA%/SwitchControl/icon-cache/

7. Frontend:
   
   - replace cyan placeholders with actual icons
   - rounded icon container
   - fallback only if extraction fails

8. Improve visual hierarchy:
   
   - icon left
   - app name
   - publisher
   - metadata badges
   - uninstall/protected state

9. Add fallback categories:
   
   - gamepad icon for gaming tools
   - chip icon for drivers
   - Microsoft icon for Windows apps

10. Never use identical cyan placeholders for all apps.

CHECKLIST:

- Installed apps display real icons
- EXE icons extract correctly
- UWP logos render
- Cache prevents repeated extraction
- Fallback icons only used when necessary
- Debloater visually matches premium Windows utilities

FINAL OUTPUT:
Professional installed-app browser with real application branding/icons and polished visual presentation.
