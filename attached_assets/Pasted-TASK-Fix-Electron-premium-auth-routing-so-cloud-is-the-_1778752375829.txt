TASK
Fix Electron premium/auth routing so cloud is the only source of truth for login, premium, billing, and device lock.

PROBLEM
Packaged Electron rewrites "/api/*" calls to the embedded local backend at "127.0.0.1".

That is wrong for auth and premium.

The local Electron backend has no "DATABASE_URL", runs in no-DB / memory mode, and cannot know real Stripe premium status. So "/api/me", premium checks, admin grants, billing, and device lock can return null/free/stale data for real buyers.

GOAL
Separate responsibilities clearly:

Cloud backend:

- "/api/me"
- "/api/auth/*"
- "/api/premium/*"
- "/api/device/*"
- Stripe/billing/admin entitlement checks
- all login/premium/device-lock truth

Local Electron backend:

- tweaks
- telemetry
- RAM cleaner
- system actions
- local Windows operations only

IMPLEMENTATION

1. Update "client/src/lib/api.ts"

Add route classification:

const CLOUD_API_ORIGINS = "https://switchcontrol.org";

const CLOUD_ONLY_API_PREFIXES = [
  "/api/me",
  "/api/auth",
  "/api/premium",
  "/api/device",
  "/api/stripe",
  "/api/billing",
  "/api/admin",
];

function isCloudOnlyApiPath(url: string): boolean {
  try {
    const parsed = url.startsWith("http") ? new URL(url) : null;
    const path = parsed ? parsed.pathname : url;
    return CLOUD_ONLY_API_PREFIXES.some(prefix =>
      path === prefix || path.startsWith(prefix + "/")
    );
  } catch {
    return CLOUD_ONLY_API_PREFIXES.some(prefix =>
      url === prefix || url.startsWith(prefix + "/")
    );
  }
}

function toCloudUrl(pathOrUrl: string): string {
  if (pathOrUrl.startsWith("http")) return pathOrUrl;
  return `${CLOUD_API_ORIGINS}${pathOrUrl.startsWith("/") ? pathOrUrl : `/${pathOrUrl}`}`;
}

2. Fix global Electron fetch interceptor.

Current behavior rewrites all "/api/*" to local backend. Change it so cloud-only routes are never rewritten.

Rules:

- If packaged Electron and route is cloud-only, rewrite "/api/me" to "https://switchcontrol.org/api/me"
- If packaged Electron and route is NOT cloud-only, rewrite to local "127.0.0.1"
- If dev Electron, keep current behavior unless cloud-only route must hit cloud

Patch logic concept:

if (url.startsWith("/api/") || url === "/api") {
  const cloudOnly = isCloudOnlyApiPath(url);

  if (isPackagedElectron && cloudOnly) {
    const cloudUrl = toCloudUrl(url);
    if (typeof input === "string" || input instanceof URL) {
      input = cloudUrl;
    } else {
      input = new Request(cloudUrl, input as Request);
    }
  } else if (isPackagedElectron && !cloudOnly) {
    const base = await resolveApiBase();
    const suffix = url.slice("/api".length);
    const absUrl = base + suffix;
    if (typeof input === "string" || input instanceof URL) {
      input = absUrl;
    } else {
      input = new Request(absUrl, input as Request);
    }
  }
}

Example:

    "/api/billing",
