F. Disable Lock Screen

ID: disable-lock-screen
Name: Disable Lock Screen
Category: Windows UX
Risk: Safe
Recommended: No
Admin: Yes

Registry:
HKLM\SOFTWARE\Policies\Microsoft\Windows\Personalization

Apply:
NoLockScreen = 1 DWORD

Revert:
Restore baseline.
If no baseline existed, remove NoLockScreen.

Check:
NoLockScreen equals 1.

Warning:
Removes the Windows lock screen before sign-in. Does not remove account password or Windows Hello.

G. Disable Transparency Effects

ID: disable-transparency
Name: Disable Transparency Effects
Category: Windows UX
Risk: Safe
Recommended: Optional
Admin: No

Registry:
HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize

Apply:
EnableTransparency = 0 DWORD

Revert:
Restore baseline or set EnableTransparency = 1.

Check:
EnableTransparency equals 0.

Important:
If this already exists, audit it only. Do not duplicate.

H. Disable Wallpaper Compression

ID: disable-wallpaper-compression
Name: Disable Wallpaper Compression
Category: Windows UX
Risk: Safe
Recommended: No
Admin: No

Registry:
HKCU\Control Panel\Desktop

Apply:
JPEGImportQuality = 100 DWORD

Revert:
Restore baseline.
If no baseline existed, remove JPEGImportQuality.

Check:
JPEGImportQuality equals 100.

Warning:
Visual-only tweak. No gaming performance gain.
