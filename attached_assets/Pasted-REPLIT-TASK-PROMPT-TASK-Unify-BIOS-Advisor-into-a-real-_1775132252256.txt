REPLIT TASK PROMPT

TASK
Unify BIOS Advisor into a real persisted feature, remove fake dashboard BIOS scoring, enforce premium access on backend BIOS and AI routes, and fix misleading BIOS photo detection status labeling. Also clean up surrounding UX so the system feels trustworthy, consistent, and production-ready.

PROBLEM
Right now the BIOS Advisor is split across multiple truths:

1. BiosAdvisor.tsx stores scan state in local React state only, so it resets on navigation.


2. The Home dashboard BIOS summary card is not guaranteed to reflect the real last BIOS analysis result.


3. AI and BIOS premium routes log premium status, but need explicit server-side premium enforcement in-route.


4. BIOS photo detections are currently labeled as "User Confirmed" automatically, which is misleading because the model is interpreting an image, not receiving direct user confirmation.


5. The app is presenting inferred firmware analysis as if it were a stable, app-wide source of truth, which damages trust.



GOAL
Make BIOS analysis a first-class persisted system with one source of truth across pages.

Required outcomes:

BIOS Advisor scan results persist across navigation and reloads

Home dashboard BIOS card reads real persisted BIOS results only

If there is no persisted BIOS scan, dashboard must clearly show “Not analyzed” instead of fake or static values

AI and BIOS premium features are enforced on the backend, not just hidden in UI

BIOS photo detections use honest status labels and confidence handling

Resulting architecture should be clean, maintainable, and ready for future extension
