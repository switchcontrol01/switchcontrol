TASK

Fix the startup experience so it feels premium and deliberate instead of rushed and slightly janky.

There are 2 issues to fix:

1. The sun streak / light sweep in the app start screen finishes too fast.
   Right now it flashes past too quickly and does not have enough time to feel cinematic or premium.

2. The transition from the startup screen into the dashboard/cards feels laggy or heavy.
   There is visible roughness when moving from app startup into the main dashboard view. It should feel smooth, intentional, and clean.

This needs to be fixed properly, not hidden with random delays.
Keep the premium SwitchControl feel:
matte dark base
neon blue / violet glow
smooth motion
high-end feel
no cheap loader behavior

PROBLEM

Current startup sequence has 2 quality issues:

1. Sun streak is too short
   The light streak effect ends too quickly, so it feels accidental instead of designed.
   It should have a longer, cleaner pass across the intro.

2. Startup to dashboard handoff is not smooth
   When the intro hands off into the dashboard, it feels like:
   the dashboard mounts too heavy
   too many cards animate at once
   main content appears before layout is settled
   render work is happening during the transition
   the motion timing between splash exit and dashboard entry is not coordinated

Result:
the app loses polish exactly at the first impression moment

GOAL

Make startup feel premium and controlled.

Desired result:

1. Intro animation
   The sun streak / light sweep should last longer and feel more cinematic.
   It should glide, not flash.

2. Transition handoff
   The move from startup screen to dashboard should be smooth and coordinated.
   No stuttery feeling.
   No heavy card burst.
   No messy overlap between splash exit and dashboard mount.

3. Dashboard entry
   The dashboard should appear in a staged, fluid way after the splash completes.
   The handoff should feel like one continuous sequence.

IMPLEMENTATION

1. Slow down and refine the sun streak
   Find the startup / splash screen animation component and extend the sun streak duration.

Adjust:
longer duration
slightly smoother easing
slightly longer tail / fade if needed
optional very small delay before the streak begins so it reads clearly

Do not make it cartoonish.
It should feel premium, subtle, and intentional.

Target feel:
not instant
not dramatic
just clearly longer than now

If the streak currently feels like a fast flash, make it feel like a smooth cinematic pass.

2. Audit the startup-to-dashboard handoff
   Check the exact transition path from:
   startup screen
   to app shell
   to dashboard/cards

Find where:
the splash state ends
dashboard mounts
dashboard cards animate
telemetry / expensive sections render
initial data loads kick in

The lag is likely from too much happening at once.

Fix by coordinating:
splash exit
main layout reveal
dashboard card reveal
heavy widget rendering

3. Prevent heavy dashboard render during the visual handoff
   Do not let the main dashboard do all expensive work at the exact same moment the splash disappears.

Possible fixes:
mount dashboard shell first, then reveal cards in sequence
defer non-critical card animations by a short stagger
delay expensive graphs / live widgets until after first paint
memoize any derived dashboard calculations that are re-running on startup
avoid triggering too many Framer Motion animations in parallel on first mount
avoid layout thrash from measuring + animating + data updates all at once

Prioritize perceived smoothness over showing everything instantly.

4. Make the dashboard enter in layers
   The dashboard should not slam in all at once.

Preferred order:
app shell / structure appears first
hero or top summary appears next
cards reveal with light stagger
heavier live components load after the structure is stable

This should feel smooth, not delayed.
The user should feel flow, not waiting.
