STEP 1 — CREATE A SINGLE DESIGN SYSTEM USED EVERYWHERE
1) Global tokens (CSS variables + Tailwind usage)
Create a design token file and apply globally:
- Background layers: base, mid haze, top bloom
- Glass surface: background opacity, blur amount, border color, inner highlight
- Glow: accent glow (purple/cyan/teal), soft ambient glow
- Typography: hero, h2, h3, body, caption
- Radii: consistent rounded corners
- Shadows: soft + premium only (no harsh drop shadows)

2) Global background stack (must be consistent across all pages)
Build these primitives first, then use everywhere:
- BackgroundStage: layered gradient mesh + subtle grid contour + soft orbs
- SpotlightOverlay: desktop only mouse-follow radial light, pointer-events none
- NoiseOverlay: subtle film grain
- ParticleLayer: ultra subtle. Disabled on mobile and respects reduced motion
- PageTransitionWrapper: consistent page entrance/exit motion

3) Reusable UI primitives (build BEFORE editing pages)
- LayoutShell: shared header + footer + page wrapper + max widths + spacing
- GlassCard: consistent glass style for cards/blocks
- MattePanel: for legal pages readability (privacy, terms)
- GlowButton: primary CTA with glow and hover micro-motion
- GhostButton: secondary CTA minimal
- SectionHeader: consistent section title + subtitle + spacing
- FeatureGrid: 2–3 columns desktop, 1 column mobile, staggered reveal
- ShowcaseBlock: larger “hero-like” section container with depth
- StatRow / ProofRow: for trust, metrics, benchmark proof where present
- Divider: subtle gradient divider and spacing

4) Motion system (Framer Motion)
Single motion language only:
- page enter: opacity 0 -> 1, y 12 -> 0, blur 6 -> 0, duration 0.45–0.6
- section reveal: fade-up only
- card hover: scale 1.00 -> 1.02, translateY -2, duration 0.18
- stagger lists: 60–90ms per item
- respects prefers-reduced-motion (disable spotlight + particles + heavy transitions)

5) Responsive system
- Define breakpoints and spacing scale
- Mobile-first layout: no horizontal scroll ever
- Tap targets >= 44px
- Avoid hover-only interactions; ensure touch equivalents
