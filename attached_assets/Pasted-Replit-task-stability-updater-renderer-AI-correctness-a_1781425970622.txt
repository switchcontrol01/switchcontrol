1. Startup White Flash Fix
   ==================================================

Root cause:
Electron BrowserWindow backgroundColor uses #07090D while the rendered CSS app background uses #14181D.

This creates a visible color handoff during Chromium surface swap.

Fix:
In electron/main.js:

Change:
backgroundColor: '#07090D'

To:
backgroundColor: '#14181D'

Do NOT modify:

- show: false
- ready-to-show logic
- splash sequencing
- fallback timer

The white flash is caused by color mismatch only.

2. EpicDetector Fixes

Replace hardcoded drive roots.

Current:

- C:\
- D:\

Problem:
Epic manifests are actually stored under ProgramData and users on custom drive layouts silently fail detection.

Replace with:

const programData = process.env.ProgramData || "C:\ProgramData";

const EPIC_MANIFEST_ROOTS = [
path.join(
programData,
"Epic\EpicGamesLauncher\Data\Manifests"
),
];

Also:

- convert fs.readdirSync -> fs.promises.readdir
- convert fs.readFileSync -> fs.promises.readFile

Do not block Electron main thread during scans.

Add secondary DLC filter:

const cats = m.AppCategories ?? [];

if (
cats.length > 0 &&
!cats.some(c =>
c.toLowerCase().includes("games")
)
) continue;

Add warning logging for corrupted manifests:

"[EpicDetector] Failed manifest parse:",
item
);
