PATCH: Fix missing blueprint overlays, unify section background, and add subtle hero text motion

PROBLEM

The website still has three clear visual issues:

1. The uploaded blueprint overlay images are not visibly appearing in the background.
2. Different sections have different background colors/surfaces, which breaks the continuous premium atmosphere.
3. The hero headline is static and does not have subtle premium motion like the rest of the hero.

This is now a rendering and layering problem, not a design direction problem.

AIM

Fix the landing page so that:

- blueprint overlay images are actually visible as subtle background atmosphere
- all sections inherit one continuous shared background instead of isolated dark slabs
- hero text has subtle float / motion and feels alive, but not gimmicky

WHAT WE ARE ACHIEVING

The page should feel like one continuous premium environment.

The overlays should be visible enough to support the atmosphere without turning into wallpaper.

The hero text should feel slightly lifted and alive.

IMPLEMENTATION

STEP 1: FIX BLUEPRINT OVERLAY VISIBILITY

File:
client/src/components/website/BlueprintImageOverlay.tsx

The current blueprint overlay treatment is too weak or being visually buried.

Make these changes:

- increase visible opacity
- reduce blur
- keep pointer-events none
- keep absolute positioning
- keep them behind content

Rules for all three images:

- mix-blend-mode: screen
- opacity range:
  - chip: 0.14
  - graphs: 0.11
  - parts: 0.10
- blur:
  - 2px to 3px only
- remove any excessive contrast/filter stacking
- keep slow drift, but do not change the motion timing

Do NOT:
- use opacity below 0.09
- use blur above 4px
- use full-screen cover
- mount them inside text or card components

Important:
The overlays must remain environmental and visible at first glance, but still subtle.

STEP 2: FIX BACKGROUND STACKING ORDER

File:
client/src/components/website/WebsiteBackground.tsx

Ensure the render order is exactly this:

1. base dark foundation
2. gradient foundation
3. background glow hotspots
4. background image overlays
5. BlueprintImageOverlay
6. SVG line/trace overlays
7. beams / sun streaks
8. particles / spotlight / noise

If BlueprintImageOverlay is currently rendered before the gradients or behind large fog/blur layers, move it so it sits AFTER gradients and AFTER background images, but BEFORE heavy atmosphere overlays.

Strict rule:
BlueprintImageOverlay must be in the visible background stack, not hidden under gradient wash or overpowered by later fog layers.

STEP 3: UNIFY ALL SECTION BACKGROUNDS

Files:
client/src/pages/Landing.tsx
client/src/pages/Pricing.tsx
client/src/pages/Download.tsx
and any shared section component if applicable

Search for section wrappers using:
- bg-white
- bg-background
- bg-card
- solid background colors
- dark slabs that override the page atmosphere

Replace those with:
- transparent backgrounds
- no local section background unless absolutely required

Every major section must inherit the same shared WebsiteBackground atmosphere.

Allowed:
- translucent glass cards
- section glow overlays

Not allowed:
- section-wide solid surfaces that create visible color changes

STEP 4: STRENGTHEN SECTION BLENDING

File:
client/src/index.css

Strengthen the existing section glow so sections transition into each other more naturally.

Update section glow treatment so it is visible enough to bridge between sections.

Use a radial glow like:

- purple core
- transparent falloff
- large blur radius
- moderate opacity

Rule:
This must smooth the transition, not create a visible blob.

STEP 5: ADD SUBTLE HERO TEXT FLOAT

File:
client/src/pages/Landing.tsx

Locate the hero headline wrapper.

Add a dedicated animation wrapper around the full headline block only.

This should animate:
- Y offset: 0 to -6px to 0
- duration: around 7s to 9s
- easing: ease-in-out
- infinite
- very subtle

Do NOT:
- animate the entire hero section
- make the text bob dramatically
- rotate it
- add aggressive parallax

The motion should feel premium and almost subconscious.

STEP 6: ADD HERO TEXT MOTION CSS

File:
client/src/index.css

Add a new class for hero text float.

Example behavior:
- slow float upward and back down
- no jitter
- no large transform values

Also disable on:
- mobile if needed
- prefers-reduced-motion

STEP 7: VERIFY HERO TEXT STACK

File:
client/src/pages/Landing.tsx

Make sure the hero text wrapper is layered above:
- WebsiteBackground
- blueprint overlays
- svg background traces

And below only:
- optional light sweep text sheen if one exists

The headline must remain fully readable at all times.
