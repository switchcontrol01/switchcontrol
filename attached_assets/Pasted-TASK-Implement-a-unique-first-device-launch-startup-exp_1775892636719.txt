TASK

Implement a unique first-device-launch startup experience for SwitchControl.

GOAL

Create a premium, cinematic first-launch-only startup sequence that plays only the very first time a specific device opens SwitchControl.

This must feel more unique and identity-driven than the normal startup animation.

IMPORTANT RULES

This sequence must play ONLY when the app is opened on a device ID that has never completed first-launch onboarding before.

It must NOT replay when:

- the user updates the app
- the user reinstalls the app
- the user clears app data locally
- the user resets settings
- the app version changes
- the user reopens the app later

It should ONLY replay if the device ID is actually different.

This is critical.

DO NOT rely on weak frontend-only flags like simple localStorage booleans if they can be lost on reinstall or reset.

REQUIRED BEHAVIOR

1. On app launch:

- resolve device ID
- check whether this device ID has already completed the first-launch intro
- if not, play first-launch animation once
- mark first-launch animation completed for that device ID
- all later launches fall back to the standard startup animation

2. The state must survive:

- app updates
- reinstalls where possible within the existing device/account model
- local app reset
- normal cache clearing

3. If the device ID changes, the first-launch sequence may play again.

DESIGN DIRECTION

This first-launch animation must feel:

- cinematic
- fluid
- premium
- more distinctive than the regular splash
- not cheesy
- not generic
- not hacker-themed nonsense

It should feel like:

- the machine has been recognized
- SwitchControl is taking control
- a serious optimization environment is starting

DURATION

Keep it short and strong:

- target 2.5s to 4s max

Do not make it too long.

STRUCTURE

Suggested sequence:

1. dark ambient fade-in
2. subtle system/device recognition pulse
3. logo reveal with layered glow and depth
4. one strong noticeable tagline appears
5. smooth transition into normal app startup/dashboard flow

TAGLINE

Use a much stronger tagline than the current normal one.

Create a few internal options and choose the best one for the existing visual direction.

The final tagline must feel unique and high-end, not generic marketing filler.

Examples of direction only:

- Every millisecond counts.
- This machine is now under control.
- Your PC just entered a different class.
- Precision begins here.

Do not blindly use these unless they fit best. Choose the strongest final line for the actual animation.
