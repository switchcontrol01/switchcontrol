That crash is simple. The method literally does not exist on your Electron version.

You added:

mainWindow.webContents.setBackgroundColor('#07090D');

But webContents.setBackgroundColor() is not a valid Electron API in Electron 33.4.11.

That is why the app hard crashes during startup before the window even finishes creating.

Remove it completely.

Use ONLY:

backgroundColor: '#07090D'

inside BrowserWindow.

Your real dark-stack should be:

const mainWindow = new BrowserWindow({
  width: 1600,
  height: 1000,
  show: false,
  backgroundColor: '#07090D',
  paintWhenInitiallyHidden: true,
  webPreferences: {
    preload: path.join(__dirname, 'preload.js'),
    contextIsolation: true,
    nodeIntegration: false,
  }
});

Then:

mainWindow.once('ready-to-show', () => {
  requestAnimationFrame(() => {
    requestAnimationFrame(() => {
      requestAnimationFrame(() => {
        mainWindow.show();
      });
    });
  });
});

And REMOVE this entirely:

mainWindow.webContents.setBackgroundColor(...)

That recommendation earlier was wrong because Chromium compositor color APIs changed across Electron versions and that method exists in some Chromium embeddings but not your Electron runtime.
