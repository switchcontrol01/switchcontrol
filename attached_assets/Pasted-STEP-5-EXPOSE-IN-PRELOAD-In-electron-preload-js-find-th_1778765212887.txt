In electron/preload.js, find the section where other IPC bridges are exposed. Add a processControl namespace following the exact same pattern used for existing namespaces. Expose:

    applyCompetitive: () => ipcRenderer.invoke('processControl:applyCompetitive')

    restoreLast: () => ipcRenderer.invoke('processControl:restoreLast')
    getLastResult: () => ipcRenderer.invoke('processControl:getLastResult')
    getProtectedList: () => ipcRenderer.invoke('processControl:getProtectedList')

STEP 6: CREATE THE HOOK

Create client/src/hooks/useProcessControl.ts.

This hook manages all Process Control state. It must:

    Store status, scanResult, lastResult, actionPlan, beforeAfter using useState
    Expose a scan() function that calls window.electronAPI.processControl.scan(), sets status to scanning before and idle after, stores result, never calls scan automatically on mount unless lastResult is null
    Expose applySafe(), applyCompetitive(), applyExtreme(plan) functions that set status to applying, call the IPC, set status to verified on success
    Expose restoreLast() that calls the IPC and returns the restore result
    Expose getProtectedList() that calls the IPC once on first use and caches the result
    Never trigger a scan from a useEffect with no dependencies. Scan only when explicitly called.
    Use useRef for single-flight guards to prevent double-invocation from React StrictMode

Return all state and all functions from the hook.
