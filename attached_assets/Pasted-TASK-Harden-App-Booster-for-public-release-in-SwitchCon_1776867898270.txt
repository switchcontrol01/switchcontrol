Electron local backend is still rejecting the auth path in some cases:

Required outcome:

2. Determine exact failure mode

- stale cached JWT
- wrong secret
- wrong issuer / audience

- request made before token is refreshed
- cookie/session mismatch

- blindly allowing requests from localhost without real auth logic
