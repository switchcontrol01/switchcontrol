TASK
Upgrade the SwitchControl website with advanced premium scroll animations and cinematic UI effects.

IMPORTANT
This is for the marketing website only.
Do not apply these effects inside the Windows desktop app.

GOAL
Make the SwitchControl website feel far more premium, modern, animated, and memorable while keeping it fast, stable, mobile-friendly, and trustworthy.

The site should feel like:

- premium gaming software
- advanced Windows performance console
- cinematic tech product launch
- clean, engineered, smooth, expensive

Not:

- generic SaaS template
- crypto landing page
- laggy portfolio site
- overanimated agency demo
- fake AI website

DO NOT BREAK
Do not break:

- routing
- auth
- download links
- Stripe/payment links
- mobile layout
- SEO metadata
- existing content meaning
- existing server routes
- existing app download flow

PERFORMANCE RULES
This is critical.

Requirements:

- no lag on page entry
- no jank while scrolling
- mobile must stay smooth
- no giant unoptimized images
- no infinite heavy animation loops
- no heavy canvas unless paused offscreen
- no blur animation spam
- no layout width/height animation
- no 100+ ScrollTriggers
- kill GSAP timelines on unmount
- respect prefers-reduced-motion
- disable or simplify heavy effects on mobile
- use transform and opacity only where possible
- lazy-load below-fold visuals
- preload only the hero-critical assets
- use WebP/AVIF optimized assets
- keep Lighthouse performance in good range

TECH STACK
Install and use only if needed:

- gsap
- ScrollTrigger
- Lenis optional, only if it does not break native mobile scroll

Use:

- GSAP for hero and scroll storytelling
- CSS for lightweight scroll text effects where possible
- Framer Motion only for small UI interactions if already in project
- IntersectionObserver fallback for unsupported CSS scroll-timeline

Create a scroll-driven sticky text section.

Behavior:

- section headline stays sticky
- lines brighten when centered
- inactive lines dim
- subtle cyan/violet color shift
- background grid or soft gradient stays fixed
- smooth scroll-controlled emphasis

Use for:
“Why SwitchControl is different”

Example lines:

- Most tweak apps just flip settings and hope.
- SwitchControl verifies real Windows state.
- Tweaks are tracked before they are changed.
- Rollback is built into the system.

- No fake ping boosts.
- Real optimization needs proof.

Implementation:

- prefer CSS scroll-timeline/view-timeline where supported
- fallback to IntersectionObserver active classes
- no heavy JS scroll loop
