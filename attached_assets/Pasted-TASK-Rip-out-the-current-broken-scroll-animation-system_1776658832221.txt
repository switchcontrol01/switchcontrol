TASK

Rip out the current broken scroll animation system and replace it with one unified Framer Motion reveal system.

PROBLEM

The app currently uses two separate scroll reveal systems:

- useRevealOnScroll
- AnimateIn

This is causing overlapping behavior, inconsistent timing, delayed reveals, global DOM resets, and poor motion quality.

useRevealOnScroll is especially bad because it:

- queries the full document
- resets all [data-reveal] elements globally
- uses MutationObserver on document.body
- uses timeout hacks
- uses an emergency fallback reveal timer

This is not a premium motion system.
It is fragile patchwork.

GOAL

Use one single reveal system for all on-scroll section reveals across the app.

It must be:

- smooth
- consistent
- subtle
- reliable
- reusable across all tabs

IMPLEMENTATION

1. Delete old systems

Remove usage of:

- useRevealOnScroll
- AnimateIn
- any CSS class based reveal system using [data-reveal], .is-visible, .animate-in-wrapper, or .animate-in-visible

These should no longer control motion.

2. Create one shared reveal component

Create:

client/src/components/motion/Reveal.tsx

Use Framer Motion plus a single IntersectionObserver-based hook or useInView from framer-motion.

The component should support:

- children
- delay
- y offset
- blur amount
- once
- className
- optional stagger for grouped children

3. Base animation values

Default reveal motion should be restrained:

initial:

- opacity: 0
- y: 14
- filter: blur(6px)

animate in:

- opacity: 1
- y: 0
- filter: blur(0px)

transition:

- duration: 0.55
- ease: [0.22, 1, 0.36, 1]

Viewport trigger:

- once: true
- margin: "0px 0px -8% 0px"
- amount: 0.12

4. Add a group variant

Also create support for grouped reveals:

RevealGroup

- parent controls staggerChildren
- child uses same motion style
- stagger should be subtle, around 0.06 to 0.1
- no huge stagger chains

5. Use React-owned state only

Do not:

- query document globally
- toggle classes with classList
- observe document.body mutations
- use emergency reveal timers
- reset reveal states on route change manually

Each component should own its own reveal lifecycle.

6. Keep route transitions separate

Do not mix this with AppLayout page transition logic.

AppLayout route motion stays responsible only for full page enter/exit.

Reveal component is only for sections/cards inside pages.

7. Migrate all pages

Replace old scroll reveal usage across:

- Dashboard
- Tweaks
- Power Plan
- App Booster
- Focus Mode
- Network Tweaks
- Cleaner
- Debloat
- Startup
- AI Advisor
- BIOS Advisor
- Security
- History
- Settings

8. Quality rules

The final result must:

- never rely on MutationObserver hacks
- never globally reset all reveal nodes
- never replay awkwardly while scrolling
- never stack multiple reveal systems
- never over-blur text
- feel identical across all pages

CODE

Create this exact base component:

import { motion, useInView } from "framer-motion";
import { useRef } from "react";
import { cn } from "@/lib/utils";

interface RevealProps {
  children: React.ReactNode;
  className?: string;
  delay?: number;
  y?: number;
  blur?: number;
  once?: boolean;
}

export function Reveal({
  children,
  className,
  delay = 0,
  y = 14,
  blur = 6,
  once = true,
}: RevealProps) {
  const ref = useRef<HTMLDivElement | null>(null);
  const inView = useInView(ref, {
    once,
    margin: "0px 0px -8% 0px",
    amount: 0.12,
  });

  return (
    <motion.div
      ref={ref}
      className={cn(className)}
      initial={{ opacity: 0, y, filter: `blur(${blur}px)` }}
      animate={
        inView
          ? { opacity: 1, y: 0, filter: "blur(0px)" }
          : { opacity: 0, y, filter: `blur(${blur}px)` }
      }
      transition={{
        duration: 0.55,
        delay,
        ease: [0.22, 1, 0.36, 1],
      }}
    >
      {children}
    </motion.div>
  );
}

Also create a grouped version:

import { motion } from "framer-motion";
import { cn } from "@/lib/utils";

export function RevealGroup({
  children,
  className,
}: {
  children: React.ReactNode;
  className?: string;
}) {
  return (
    <motion.div
      className={cn(className)}
      initial="hidden"
      whileInView="visible"
      viewport={{ once: true, margin: "0px 0px -8% 0px", amount: 0.1 }}
      variants={{
        hidden: {},
        visible: {
          transition: {
            staggerChildren: 0.08,
          },
        },
      }}
    >
      {children}
    </motion.div>
  );
}

export function RevealItem({
  children,
  className,
}: {
  children: React.ReactNode;
  className?: string;
}) {
  return (
    <motion.div
      className={cn(className)}
      variants={{
        hidden: { opacity: 0, y: 14, filter: "blur(6px)" },
        visible: {
          opacity: 1,
          y: 0,
          filter: "blur(0px)",
          transition: {
            duration: 0.55,
            ease: [0.22, 1, 0.36, 1],
          },
        },
      }}
    >
      {children}
    </motion.div>
  );
}
