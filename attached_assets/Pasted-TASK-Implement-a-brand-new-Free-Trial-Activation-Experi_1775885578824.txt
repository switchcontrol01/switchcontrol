TASK

Implement a brand new Free Trial Activation Experience for SwitchControl across frontend, backend, and app state.

This is for when an admin grants a user a free trial.

When that user next opens the app, signs in, refreshes account state, or regains entitlement from free to trial, SwitchControl must detect that their plan changed to an active free trial and trigger a premium-feeling trial activation sequence.

This must include:

- a cinematic activation animation
- a short guided free trial tour
- trial countdown and duration clarity
- elegant graphs and live visuals
- smooth micro-animations throughout
- proper backend-backed enforcement
- no fake frontend-only trial state

The result must feel premium, exciting, polished, and emotionally convincing, while still being clean and believable.

GOAL

I want free trial users to instantly feel that they unlocked something valuable.

The activation should:

- clearly tell them trial access is active
- explain what they now have access to
- show exactly how long the trial lasts
- encourage them to explore the best premium features quickly
- feel cinematic, fluid, and polished
- match the SwitchControl glass neon design language

This is not just a popup.
This is a full onboarding moment for trial users.

CRITICAL RULES

- Detect trial activation from real backend account state only
- Do not fake trial status in frontend
- Do not trigger repeatedly every launch once already seen
- Must work in app and website account state model consistently
- Must support free -> trial transitions triggered by admin
- Must not break premium unlock flow
- Trial and premium activation flows must remain distinct
- Motion must feel smooth and premium, not cheap or spammy

IMPLEMENTATION

1. TRIAL ACTIVATION DETECTION

Implement server-backed trial activation detection.

Need logic so frontend can detect:

- user was previously free
- user is now trial-active
- user has not yet seen the trial activation sequence

Add any fields needed cleanly, such as:

- hasSeenTrialActivation
- hasSeenTrialTour
- trialActivatedAt
- trialEndsAt

Need a clean helper such as:

- resolveEffectivePlan(user)
- isTrialActive(user)
- shouldShowTrialActivation(user, previousUserState)

Trigger sequence when:

- plan is trial
- trial is active
- user has not seen activation yet

Do not trigger:

- if trial already expired
- if user is premium
- if already seen
- if account refresh happens repeatedly after seen

2. NEW FREE TRIAL ACTIVATION ANIMATION

Create a completely separate activation sequence for free trial users.

This must NOT reuse the premium unlocked animation with just text swaps.
It needs its own identity.

Design direction:

- cinematic but slightly lighter than premium
- premium-adjacent feeling
- bright cyan, violet, electric blue, subtle emerald accents
- translucent glass panels
- ambient glow
- smooth layered blur
- particles, trails, gradient bloom, data energy
- elegant animated graphs or signal traces
- premium-level transitions

Mood:

- "You now have temporary elite access"
- exciting
- urgent in a good way
- polished
- high-value
- modern
- premium software feel

Animation phases:

1. darken / ambient build
2. trial unlock signal appears
3. access ring / pulse / glow sequence
4. logo reveal or access card reveal
5. short graph/data flourish
6. text reveal
7. CTA reveal
8. optional smooth exit into trial tour

Do not make it cheesy.
Do not make it too long.
Target around 3.5 to 5.5 seconds total unless reduced motion applies.

5. SHORT FREE TRIAL TOUR

After activation, show a short trial-specific guided tour.

This should be shorter than full onboarding and shorter than premium tour.

Goal:

- quickly guide users to the most valuable premium features
- avoid too many steps
- make trial users understand what to use first

Target 3 to 5 steps max.

Suggested flow:

1. Welcome to Free Trial
2. AI Advisor or best premium differentiator
3. BIOS Advisor or advanced tweaks
4. Network / performance / power plan premium tools
5. Trial countdown + where to upgrade later

Each step must:

- feel premium
- include preview visuals
- include small motion and graph animation if relevant
- clearly explain benefit
- remind user this access is limited-time

Need a distinct trial palette from premium:

- still premium feeling
- but not identical to paid premium onboarding
