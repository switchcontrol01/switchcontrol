TASK
Fix all info modals changing from glass to milky/opaque after opening.

PROBLEM
When clicking any info button on General Tweaks or Network Tweaks, the modal first appears glassy, then after a moment becomes milky/washed out. This is caused by layered blur/backdrop/filter effects stacking between:
- modal backdrop
- GlassModalSurface
- motion animation
- parent page glass cards
- possible duplicate blur classes

GOAL
Info modals must stay consistently glassy/transparent from open to close. No milky white overlay. No opacity shift after 0.3s.

IMPLEMENTATION

1. Audit these files:
- client/src/components/tweaks/TweakCard.tsx
- Network tweak card/info modal component
- client/src/components/ui/GlassModalLayout.tsx
- any shared modal/backdrop component
- motion.ts modalBackdrop/modalContent variants

2. Remove stacked backdrop blur
The backdrop should dim only. It must NOT blur.

Use:
className="fixed inset-0 z-40 bg-black/45 pointer-events-auto"

Do not use:
backdrop-blur
backdrop-saturate
bg-white/...
filter blur
opacity animation that changes final glass look

3. Make modal surface single-source glass
GlassModalSurface must own the glass effect. Nothing else should add another glass layer.

Set final style similar to:
bg-[#0b1020]/70
border border-white/10
shadow-2xl
backdrop-blur-xl

Do not stack GlassCard inside GlassModalSurface.

4. Lock animation final state
Check modalContent variants. Final animate state must not change background, blur, filter, or opacity after mount.

Correct:
initial: { opacity: 0, scale: 0.96, y: 10 }
animate: { opacity: 1, scale: 1, y: 0 }
exit: { opacity: 0, scale: 0.96, y: 8 }

Bad:
animate backdropFilter
animate filter
animate backgroundColor
animate opacity on nested glass layers

5. Fix portal layering
Modal should be:
backdrop z-40
modal container z-50
close button z-60

Do not render another overlay inside GlassModalSurface.

6. Apply same fix to Network Tweaks
Network tweak info modal must use the exact same modal shell as TweakCard. No separate styling that reintroduces milky blur.

7. Add debug guard
In dev only, log:
[ModalGlass] opened id=<id>
[ModalGlass] backdrop=no-blur
[ModalGlass] surface=single-glass-layer

CHECKLIST
- Open General Tweak info modal.
- Wait 3 seconds.
- It must stay the same glass look.
- Open Network Tweak info modal.
- Wait 3 seconds.
- It must stay the same glass look.
- No milky white wash.
- No double overlay.
- No stacked blur.
- No CPU/GPU-heavy animation.

FINAL OUTPUT
Return changed files and confirm there is only one glass blur layer in the modal.
