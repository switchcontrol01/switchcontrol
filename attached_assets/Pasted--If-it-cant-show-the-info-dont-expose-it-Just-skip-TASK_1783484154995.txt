TASK: Complete Display Signal Detection Overhaul & Enterprise Multi-Monitor Support

PROBLEM

The current Display Signal card relies on limited Windows information and reports multiple fields as "Unknown."

Examples include:

• HDR
• VRR
• FreeSync
• G-SYNC
• Adaptive Sync

This reduces confidence in the diagnostics and leaves valuable monitor information unavailable.

Additionally, users with multiple monitors cannot inspect individual displays because SwitchControl always shows a single monitor with no selector.

This entire system should become a professional monitor diagnostics engine.

------------------------------------------------------------

GOAL

Completely redesign the backend detection engine so Display Signal becomes one of the most comprehensive display diagnostics available in a Windows optimization application.

Do NOT rely on SystemInfo alone.

Instead combine multiple native Windows APIs and hardware interfaces to build one unified display capability model.

------------------------------------------------------------

IMPLEMENTATION

Replace the current detection logic with a dedicated Display Detection Service.

Bundle native support directly into SwitchControl using Node native modules (N-API).

Use every appropriate Windows API available.

Sources should include:

• DisplayConfig API
• DXGI
• DXCore
• Win32 Display APIs
• EDID parser
• WMI
• SetupAPI
• Monitor Configuration API
• DXDiag information where beneficial
• NVIDIA NVAPI (when available)
• AMD ADL SDK (when available)

Do not rely on only one source.

Each API should contribute the fields it exposes best.

------------------------------------------------------------

Display Signal should become a complete hardware-level monitor diagnostics engine capable of accurately detecting every connected monitor, identifying its capabilities, exposing HDR, VRR, Adaptive Sync, FreeSync, G-SYNC, GPU routing, EDID information, connection type, color information, display timing, and allowing the user to instantly switch between monitors from within the card.
