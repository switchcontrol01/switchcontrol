TASK
Build high-impact visual systems for Cleaner + Tweaks:
- Category Weight Rings
- File Gravity cleaning animation
- System Pressure Meter
- Before vs After Impact Bar

These must feel premium, responsive, and real. No fake data, no heavy CPU usage, no lag.

PROBLEM
Current UI is list-heavy, boring, and gives no feedback. Users cannot “feel” impact. Cleaning and tweaks feel fake because there is no visual result.

GOAL
Replace static lists with visual feedback systems that:
- show impact instantly
- animate only on real actions
- feel smooth and controlled
- use transform + opacity only (no layout thrashing)
- do not spike CPU

IMPLEMENTATION

--------------------------------

1. CATEGORY WEIGHT RINGS

Create component:
client/src/components/cleaner/CategoryWeightRing.tsx

PURPOSE
Visual representation of category size + selection + clean state.

PROPS
- label
- value (size or impact)
- maxValue
- selected (boolean)
- cleaned (boolean)
- delay (for stagger)
- color

UI
- circular ring (SVG)
- center label
- subtext (size)

BEHAVIOR

INITIAL (before scan)
- empty ring (0 stroke)
- low opacity

AFTER SCAN
- stroke animates from 0 → percentage
- duration: 600ms
- easing: easeOut
- slight glow appears

SELECTION
- ring gets brighter glow
- scale: 1 → 1.04 (subtle)
- border glow intensifies

CLEANED
- ring drains (stroke reduces to 0)
- fades opacity to 0.3
- label updates to 0 MB
- no layout shift

ANIMATION RULES
- use strokeDasharray + strokeDashoffset
- animate via framer-motion or CSS transitions
- no canvas
- no continuous loops

LAYOUT
Grid of rings:
- 2 rows desktop
- stacked mobile
- replaces large list

2. FILE GRAVITY ANIMATION

Create component:
client/src/components/cleaner/FileGravityCore.tsx

PURPOSE
Make cleaning feel real. Visual removal of items.

INPUT
- list of items (or categories)
- trigger (clean start)
- onComplete callback

ANIMATION

STEP 1 – PREP
- items visible in positions
- slight jitter (very subtle, optional)

STEP 2 – COLLAPSE
- each item:
  - translate toward center
  - scale 1 → 0.3
  - opacity 1 → 0
- stagger: 20–40ms per item

STEP 3 – CORE PULSE
- center core expands quickly (scale 1 → 1.3 → 1)
- glow burst
- 200ms total

STEP 4 – CLEAR
- all items removed
- cleaned state triggers UI update

PERFORMANCE RULES
- only transform + opacity
- no reflow properties
- max items rendered: cap at 30 visual elements (aggregate if needed)

FALLBACK
If too many files:
- group by category
- animate category nodes instead

3. SYSTEM PRESSURE METER

Create component:
client/src/components/dashboard/SystemPressureMeter.tsx

PURPOSE
Single readable system health score.

INPUT METRICS
- CPU %
- RAM %
- background process count (normalized)
- disk activity %

CALCULATION

pressure =
( cpu * 0.35 ) +
( ram * 0.30 ) +
( disk * 0.20 ) +
( processLoad * 0.15 )

Clamp 0–100

UI
- circular gauge (SVG arc)
- smooth fill
- numeric value in center
- label: "System Pressure"

COLOR ZONES
0–40 → green
40–70 → yellow
70–100 → red

ANIMATION
- animate value change with spring or easeOut
- duration: 400–600ms
- number counts up/down (use requestAnimationFrame)

NO CONSTANT LOOP
Only update when telemetry changes.
