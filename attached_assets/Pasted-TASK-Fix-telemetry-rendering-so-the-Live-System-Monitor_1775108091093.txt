TASK

Fix telemetry rendering so the Live System Monitor shows multiple lines (CPU, RAM, Disk, Network, GPU) instead of only CPU.

This is NOT a UI-only issue. It is caused by inconsistent IPC data shapes and incorrect visibility logic.

---

ROOT CAUSES

1. GPU telemetry returns ARRAY but frontend treats it as OBJECT
2. RAM IPC shape mismatch (missing totalGB / usedGB)
3. Network values set to null when idle
4. LiveGraph visibility depends on history instead of current state
5. Memory cleaner crash due to missing import + unsafe response handling

3. FIX RAM IPC SHAPE (electron/main.js)

Inside system:getRamUsage return:

return {
  total: mem.total,
  used: mem.total - mem.available,
  free: mem.available,
  usagePercent: Math.round(((mem.total - mem.available) / mem.total) * 100),

  totalGB: Math.round(mem.total / 1024 / 1024 / 1024),
  usedGB: Number(((mem.total - mem.available) / 1024 / 1024 / 1024).toFixed(1)),
  freeGB: Number((mem.available / 1024 / 1024 / 1024).toFixed(1)),
};

Frontend must use these consistently.
