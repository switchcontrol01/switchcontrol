TASK: Build SwitchControl BIOS Advisor (Firmware Optimization Scanner)

PROBLEM
Most users do not know if their BIOS configuration is optimal.

Important firmware settings often remain unconfigured.

Examples:
- EXPO / XMP disabled
- resize BAR disabled
- virtualization enabled unnecessarily
- memory power down mode suboptimal
- incorrect boost behavior

Users need a system that evaluates BIOS configuration.

---

AIM

Create a BIOS Advisor that scans detected hardware and current system configuration to generate a firmware optimization score.

The BIOS advisor must:

Score system firmware readiness.

Explain BIOS optimization opportunities.

Rank improvements by impact.

BIOS changes must NEVER be auto applied.

They are informational and manual only.

---

SECTION 1 — BIOS SCORE SYSTEM

BIOS Advisor must generate a score from:

0 to 100

Score categories:

CPU configuration
Memory configuration
Boot latency settings
Platform features
Device configuration

Example scoring rules:

EXPO/XMP enabled: +15  
RAM running JEDEC speeds: 0  

Resizable BAR enabled: +6  

Virtualization enabled unnecessarily: -4  

Correct PBO configuration: +8  

Memory power down mode suboptimal: -3

---

SECTION 2 — BIOS SCAN INPUTS

BIOS Advisor must analyze:

CPU model  
Motherboard model  
BIOS version (if detectable)  
RAM speed  
RAM timings if available  
GPU  
Platform generation  

User goal:
- gaming latency
- max FPS
- stability
- balanced

SECTION 3 — SCORE BREAKDOWN UI

SECTION 4 — OPPORTUNITIES LIST

Show ranked BIOS opportunities.

Each recommendation includes:

Title  
Score Gain  
Difficulty  
Risk  
Explanation

Example:

Enable EXPO

Score gain: +15  
Difficulty: Easy  
Risk: Low  

Explanation:
Your RAM is currently running at JEDEC speeds. Enabling EXPO allows the memory kit to operate at its rated speed.

Which settings matter most for this hardware.

Which changes are safe first.

Which changes are advanced.

AI must NOT invent BIOS menu paths.
