4. BIOS / firmware score
This is one of the biggest trust risks in the app.
Your current BIOS score is derived from static BIOS_SETTINGS and inference.
That means it is not truly a live firmware score yet.
So if the UI makes it look like a real detected score, that is dangerous.
Best fix
Split it into two layers:
Layer A: real detected inputs
Real values you can actually infer from OS/runtime:
memory frequency
CPU model
virtualization status
Hyper-V status
some timer traits
maybe ReBAR
maybe SMT clues
maybe thermal throttling history
maybe power plan related indicators
Layer B: inferred firmware opportunities
Everything else should be explicitly labeled:
inferred
unknown
not directly readable from firmware
UI wording must change
Not:
"Firmware score detected"
Instead:
"Firmware readiness estimate"
"Based on detected runtime indicators and inferred BIOS traits"
That protects credibility.
Best implementation
Create a real BIOS advisor pipeline:
scan source: live / mixed / inferred
confidence score
detected fields count
firmware hash
last scan timestamp
Then show:
score
confidence
source mix
detected vs inferred counts
That will feel far more premium and far more honest.

7. Tweak execution and admin
Your current admin model is not good enough.
You said you do not want the whole app always run as admin. Correct. That is the right instinct.
Best implementation
Per-action elevation.
That means:
app runs standard user by default
when a tweak requiring admin is applied or reverted:
launch elevated helper process only for that command
helper returns structured result
app remains non-elevated
Why this is the right model
safer
more trustworthy
less scary
better UX than "run app as admin always"
closer to premium software behavior
Do not do this
forcing the whole Electron app to permanently run as admin
asking the user to restart app as admin for every serious tweak set
Implement instead
A small elevated executor helper:
receives tweak id + action
runs only whitelisted commands
returns JSON result
main app verifies state afterward
That is bulletproof.
