ISSUE 1 — TAB FLASH / TRANSPARENT FLASH
CRITICAL

ROOT CAUSE:

Suspense fallback={null}

When lazy routes load:

- previous content unmounts
- React renders null
- Electron compositor shows transparent frame/background

RESULT:
The app briefly disappears and wallpaper/background shows.

==================================================
FIX REQUIRED

REPLACE ALL:

fallback={null}

WITH:

fallback={<DarkFallback />}

Create:

const DarkFallback = () => (

  <div
    style={{
      position: 'fixed',
      inset: 0,
      background: '#070b14',
      pointerEvents: 'none'
    }}
  />
)IMPORTANT:

- fallback must NEVER render null
- fallback must NEVER render transparent content
- fallback must ALWAYS paint a solid dark frame instantly

ISSUE 2 — FULLSCREEN REPAINTS
HIGH PRIORITY

Audit ALL fullscreen wrappers using:

- AnimatePresence
- motion.div
- opacity animations
- fullscreen transitions

CURRENT ISSUE:

AnimatePresence mode="sync"

This mounts:

- exiting screen
- entering screen

simultaneously.

This doubles compositor load and can create:

- fullscreen repaints
- flashes
- stutter

==================================================
FIX REQUIRED

Change:

mode="sync"

TO:

mode="wait"

Also ensure:

- app shell NEVER unmounts
- sidebar NEVER remounts
- nav NEVER remounts
- only inner route content changes
