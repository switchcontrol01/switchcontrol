13. Performance Philosophy

DO NOT:

- add more polling
- add more animations
- add more AI loops
- add more background scans
- add more “FPS tweaks”

Continue prioritizing:

- stable frametimes
- startup smoothness
- renderer stability
- minimal repainting
- minimal IPC
- minimal synchronous filesystem access
- deterministic startup order
- safe tweak behavior
- accurate telemetry
- low DPC / scheduler pressure

This project should feel smoother, quieter, and more stable than “optimizer” apps that brute-force tweaks.
