🔥 PART 2 — Smooth Scroll (Critical)

Right now it instant jumps because you're probably using:

element.scrollIntoView()

That defaults to instant.

Replace with:

element.scrollIntoView({
  behavior: "smooth",
  block: "center"
});

BUT.

Native smooth scroll is still janky.

Better:

Use a custom scroll easing function:

function smoothScrollTo(targetY: number, duration = 600) {
  const startY = window.scrollY;
  const diff = targetY - startY;
  const start = performance.now();

  function step(now: number) {
    const progress = Math.min((now - start) / duration, 1);
    const ease = 1 - Math.pow(1 - progress, 3);
    window.scrollTo(0, startY + diff * ease);
    if (progress < 1) requestAnimationFrame(step);
  }

  requestAnimationFrame(step);
}

No instant jumps.
