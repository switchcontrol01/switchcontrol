1️⃣ Rate-limit auth endpoints (REQUIRED)
Why
Prevent brute-force, spam login attempts, and abuse.
What to protect
Only these routes:
/api/auth/google
/api/auth/google/callback
/api/auth/exchange
/api/login (if exists)
DO NOT rate-limit /api/me
How to implement
Install
Copy code

npm install express-rate-limit
Add middleware (server/index.ts or app.ts)
Copy code
Ts
import rateLimit from "express-rate-limit";

const authLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100,
  standardHeaders: true,
  legacyHeaders: false,
});

app.use("/api/auth", authLimiter);
That is it.
No IP bans. No captcha. No extra logic.
2️⃣ Session rotation after login (IMPORTANT)
Why
Prevents session fixation attacks.
What to do
Rotate session after successful OAuth login only.
How to implement
In the OAuth callback handler (after user is authenticated):
Copy code
Ts
req.session.regenerate(err => {
  if (err) {
    return next(err);
  }

  req.login(user, err => {
    if (err) return next(err);
    return res.redirect(DEEP_LINK_URL);
  });
});
⚠️ Do NOT rotate sessions on every request
⚠️ Do NOT touch cookies config beyond this
3️⃣ CSRF protection (LIMITED SCOPE)
Important rule

Routes to protect
/api/settings
/api/tweaks
/api/profile
/api/purchase (if exists)
How to implement
Install
Copy code

npm install csurf
Middleware
Copy code
Ts
import csurf from "csurf";

const csrfProtection = csurf({
  cookie: false

Apply only to protected routes
Copy code
Ts

Frontend:
Fetch CSRF token once
Send via header X-CSRF-Token
DO NOT break existing auth.
