**Phase 1 — Stop SC from hurting games (Game Sentinel)**

When a boosted game's process is detected running, SC should enter a self-throttle mode. Concretely:

- Poll `tasklist` every 5 seconds to check if the game exe is running
- When detected: set `_telemetryLoopPaused = true`, cancel any pending PowerShell GPU counter calls, push the polling interval to 30s minimum
- Show a small "Game Active — SC throttled" indicator in the UI so the user knows it's running lean
- When the process exits, resume normal polling

This is the single highest ROI change. The GPU perf counter PowerShell spawns are the worst offender during gameplay.

**Phase 2 — Better optimizations for Fortnite specifically**

The current 6 actions are mostly fine but miss the high-impact ones. What to add:

**CPU scheduling fixes** — Fortnite's render thread gets preempted constantly on hybrid Intel CPUs. Setting `Win32PrioritySeparation` to `0x26` (38 decimal) gives foreground threads a massive scheduler boost. This is more impactful than CPU priority class alone. Also set the game's thread ideal processor affinity to exclude E-cores on 12th/13th/14th gen.

**NVIDIA GPU max performance** — Writing `PreferedOpenGLImageUnits` and `PerfLevelSrc = 0x2222` to the NVIDIA driver registry key forces the GPU to never downclock, eliminating the stutters caused by the GPU power state ramping up mid-frame.

**Disable HPET** — High Precision Event Timer adds interrupt overhead. `bcdedit /deletevalue useplatformclock` + disabling the HPET device via devcon is measurably better for 1% lows on most systems.

**Timer resolution** — Setting the Windows timer resolution to 0.5ms via `timeBeginPeriod(1)` reduces scheduler granularity. Your current `timer-res` tweak exists but `isSafeWindowsPath` blocks it from being used in App Booster profiles. Fix the routing.

**Disable fullscreen optimizations properly** — The current FSO disable only writes the AppCompatFlags key. You also need to set `DisableHWAcceleration` and ensure the game is running in exclusive fullscreen, not borderless. Add a check that surfaces this to the user.

**Network for Fortnite specifically** — Fortnite uses UDP on ports 9000-9100. The current QoS policy matches by exe path which is correct, but you should also add `TcpAckFrequency=1` and `TCPNoDelay=1` per-interface which your manual game profile already does — wire this into catalog games too.
