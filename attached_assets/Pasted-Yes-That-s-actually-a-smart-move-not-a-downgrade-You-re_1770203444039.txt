---

What “actually work” means (definition)

A tweak is considered working if ALL are true:

1. It performs a real Windows change


2. It is reversible


3. It is idempotent (running twice doesn’t break things)


4. It returns success / failure


5. It persists across reboots (when applicable)



If a tweak does not meet all five, it stays visual-only or is removed.


---

Architecture (this is the key part)

You do NOT run tweaks from:

React

The browser

Node server


You DO run tweaks from:

Electron main process

Local agent / privileged executor


Right now, your system is already close to this. You just need to formalize it.


---

Correct execution flow (do not change this)

UI (Tweaks page)
  ↓
Electron preload (safe bridge)
  ↓
Electron main (command dispatcher)
  ↓
Local executor (PowerShell / registry / netsh)

Never skip a layer.


---

Step-by-step: make Tweaks real

1. Categorize all tweaks (non-negotiable)

Go through your tweak list and label each as ONE of these:

Tier A – Safe (no admin)

Power plan selection

Game Mode toggle

Timer resolution (if user-mode)

Windows UI flags


Tier B – Admin required

Registry edits

Network stack tweaks

Power throttling

Core parking

MMCSS priority


Tier C – Dangerous (advanced)

TCP autotuning

Nagle / ACK delay

Interrupt moderation

MSI mode


If you mix tiers, you will break the app. Don’t.


---

2. Each tweak = one executable action

Every tweak must map to exactly one function:

Example:

applyDisableCoreParking()
revertDisableCoreParking()

No inline logic in React. Ever.


---

3. Store tweak state locally (not just DB)

You need two sources of truth:

Server: entitlement + premium

Local machine: applied / not applied


Use:

Registry

Or a local JSON file in app data


Never trust UI state alone.


---

4. Execution result contract (mandatory)

Every tweak execution must return:

{
  "success": true,
  "requiresReboot": false,
  "message": "Core parking disabled",
  "error": null
}

UI reacts to result, not hope.


---

5. Reboot handling (don’t fake this)

If a tweak needs reboot:

Show banner

Persist pending state

Re-verify on next launch


Do not lie to users.
