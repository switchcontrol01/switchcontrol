Add-on Feature: “Expected change” per tweak

Goal:
Add a compact “Expected change” row in the tweak info panel (and optionally on the card) that quickly tells the user what the tweak usually affects.

Data model:
For each tweak, add:
- expected: {
    cpu?: "None" | "Low" | "Medium" | "High",
    gpu?: "None" | "Low" | "Medium" | "High",
    ram?: "None" | "Low" | "Medium" | "High",
    disk?: "None" | "Low" | "Medium" | "High",
    network?: "None" | "Low" | "Medium" | "High",
    latency?: "None" | "Low" | "Medium" | "High",
    stabilityRisk?: "None" | "Low" | "Medium" | "High"
  }

UI changes:
1) In the info panel/modal that shows Safety / Description / Impact, add a new section between Description and Impact:
   Title: “Expected change”
   Render as small pill tags: CPU: Low, RAM: Medium, Disk: Low, Network: None, Latency: Low, Risk: Medium
2) Keep it consistent with your existing badge/pill styling.
3) If a field is missing, don’t show it.
4) Ensure values are not hardcoded and come from tweak.expected.
