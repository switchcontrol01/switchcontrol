Where this is currently leaking from

This usually comes from one or more of these places:

1️⃣ package.json

Check for:

"name": "switchcontrol-1.0"
"productName": "SwitchControl 1.0"

Correct version:

"name": "switchcontrol"
"productName": "SwitchControl"
"version": "1.0.0"

Version stays. Name does not include it.


---

2️⃣ Electron Builder config (electron-builder.yml or package.json > build)

Look for:

"productName": "SwitchControl 1.0"
"appId": "com.switchcontrol.1.0"

Fix:

"productName": "SwitchControl"
"appId": "com.switchcontrol.app"

Do not bake versions into appId.


---

3️⃣ Windows installer metadata

If you’re using NSIS (default):

Look for:

artifactName

displayName


Fix to:

SwitchControl Setup.exe

Not:

SwitchControl 1.0 Setup.exe

4️⃣ Windows Installed Apps list

Windows pulls the name from:

productName

DisplayName registry entry


If this still shows “1.0”, it means:

The installer was built with the wrong name

Windows cached the old entry


You must rebuild the installer after fixing names.
