TASK: Replace Electron Cookie Auth With JWT (Desktop Only)
WHY we are switching
Electron is running from file:// origin.
That creates persistent cross-origin cookie issues:
SameSite rules are fragile
CORS must be perfectly configured
Proxies/CDNs can rewrite cookies
Session middleware can conflict
Cookies silently fail to store
/api/me returns loggedIn=false even after successful login
Causes premium flicker + forced logout behavior
We have already spent significant time stabilizing cookies.
The architecture itself is the problem.
Desktop apps should not rely on browser session cookies.
JWT solves this cleanly because:
No SameSite dependency
No CORS cookie dependency
No Electron cookie store reliance
No express-session requirement
Stateless verification
Clear Authorization header
Predictable behavior
Website (30% traffic) can keep cookies.
Desktop (primary target) moves to JWT.
This isolates complexity.
IMPLEMENTATION REQUIREMENTS
DO NOT refactor UI.
DO NOT remove session middleware.
Website must continue working unchanged.
