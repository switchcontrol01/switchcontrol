4. ADD BEFORE / AFTER SYSTEM REACTION TRACKING
When a tweak is applied, the page should not just flip a toggle.
It should show system reaction.

Need post-apply tracking where possible:
- state changed successfully
- verification passed
- relevant system condition changed / unchanged
- improvement signal detected / not detected
- maybe delayed evaluation if effect needs time

Examples:
- Background services reduced
- Startup impact unchanged
- Memory pressure unchanged
- Responsiveness signal improved slightly

Do NOT overclaim.
If there is no measurable effect, say so.
