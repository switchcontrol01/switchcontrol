PRIORITY 1 — STARTUP FLASH FIX

The startup white flash root cause has been identified.

Electron BrowserWindow background:
'#07090D'

CSS app background:
'#14181D'

This mismatch creates a visible frame during Chromium handoff.

FIX:

In:
electron/main.js

Change:

backgroundColor: '#07090D'

TO:

backgroundColor: '#14181D'

DO NOT modify:

- ready-to-show logic
- splash timing
- show:false logic

The issue is purely the color mismatch between the native surface and rendered surface.

PRIORITY 2 — CLOUD TRUTH ROUTE SECURITY

CRITICAL ISSUE:

/api/device is missing from CLOUD_TRUTH_ROUTE_PREFIXES.

This creates a defense-in-depth gap where local Electron backend device validation could incorrectly succeed using mock/in-memory storage.

FIX:

Add:

'/api/device'

to CLOUD_TRUTH_ROUTE_PREFIXES.

Goal:
Prevent ANY local backend handling of premium/device truth routes.

PRIORITY 4 — EPIC DETECTOR CORRECTNESS

CURRENT ISSUE:

Epic manifest roots are hardcoded to:
C:
D:\

Users with custom ProgramData locations or other drives fail detection silently.

FIX:

Replace hardcoded roots with:

const programData = process.env.ProgramData || "C:\ProgramData";

Then derive manifest paths dynamically.

PRIORITY 5 — DEVICE BINDING MIGRATION SAFETY

CURRENT ISSUE:

Migration loop has no try/catch.

A failed ALTER TABLE can leave partial schema state silently.

FIX:

Wrap EACH migration in try/catch.

Log:

- migration failure
- shortened SQL preview
- actual error

Then rethrow.

DO NOT silently continue after failed migrations.
