C:
D:\

This silently fails for users with:

- enterprise Windows layouts

FIX

Replace hardcoded roots with:

const programData =
process.env.ProgramData || "C:\ProgramData";

path.join(
programData,
"Epic\EpicGamesLauncher\Data\Manifests"
),
];

GOAL:

- dynamic detection
- correct Windows behavior
- no drive assumptions

==================================================
ISSUE 2 — DLC FILTER FRAGILITY [LOW]

Current logic:

if (
m.MainGameCatalogItemId &&
m.CatalogItemId !== m.MainGameCatalogItemId
) continue;

This works for many manifests but is fragile.

Some DLC manifests omit MainGameCatalogItemId.

==================================================
FIX

Add AppCategories secondary validation:

const cats = m.AppCategories ?? [];

if (
cats.length > 0 &&
!cats.some(c =>
c.toLowerCase().includes("games")
)
) {
continue;
}

GOAL:

- more reliable base-game filtering
- fewer false positives
- safer launcher detection
