REQUIRED FIXES

1. GLOBAL POLLING REGISTRY
Create a lightweight debug registry that tracks:
- interval name
- source file
- interval ms
- active/inactive
- created timestamp
- last tick timestamp
- tick count

Every interval or polling loop must register itself.
On cleanup it must unregister.

Add a debug method:
window.electronAPI.performance.getPollingRegistry()
or IPC equivalent.

2. SINGLE TELEMETRY LOOP GUARANTEE
Telemetry loop must be singleton.
If startTelemetryPolling() is called twice, it must not create a second loop.
Log this clearly:

[Perf] telemetry loop already active, skipping duplicate start

3. POWERHELL AUDIT
Every PowerShell / WMI / exec / execFile call must go through one limiter/logger.
Log:
- command category
- reason
- start time
- duration
- whether it ran while app idle
- whether it ran while minimized

During idle dashboard, there should be ZERO recurring PowerShell calls.

4. IDLE MODE
When app is idle:
- no scans
- no full syncAll
- no repeated tweak checks
- no repeated service/process scans
- no repeated security scans
- no repeated PowerShell
