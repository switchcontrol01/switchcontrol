TASK

Add a GPU Details modal to the GPU info icon using real available data only.

PROBLEM

The GPU info icon is effectively useless right now because it was assumed there was not enough data to show.

That assumption is wrong.

"systeminformation.graphics()" does provide useful static GPU information such as:

- vendor
- model
- vendorId
- deviceId
- bus
- vram
- vramDynamic
- subVendor on supported platforms

At the same time, it does not guarantee full live telemetry like fan speed, power draw, temperature, or live utilization through that static graphics API.

GOAL

Make the GPU icon open a real, useful modal that combines:

1. static GPU identity from "systeminformation.graphics()"
2. live telemetry from the existing telemetry pipeline where available

Do not show fake values.
Do not imply unsupported fields exist if they are not actually collected.

IMPLEMENTATION

1. Add GPU modal opening behavior

When clicking the GPU info icon/card action:

- open a GPU Details modal

2. Use static GPU identity from "systeminformation.graphics()"

Populate the modal with the real supported static fields where available:

- model
- vendor
- subVendor
- vendorId
- deviceId
- bus
- vram
- vramDynamic
- external

3. Merge in existing live telemetry only if already collected

If the current telemetry layer already has these fields, show them in a separate Live Telemetry section:

- gpu load
- gpu temperature
- vram used
- vram total
- vram percent
- clock MHz

Only show values that actually exist in backend/runtime data.

4. Do not fake unsupported metrics

Do NOT fabricate or hardcode fields like:

- fan speed
- power draw
- driver version
- memory clock
- core clock
- hotspot temp

unless those are truly available from the backend on that machine.

If unavailable, either:

- omit the row
  or
- show "Unavailable"

5. Modal structure

Section 1:
GPU Identity

Section 2:
Live Telemetry

Section 3:
Availability note

Example note:
"Some GPU metrics depend on driver support and backend telemetry availability."

6. Hard truth rule

The modal must reflect actual backend truth only.

No placeholder premium-looking fake hardware stats.
No guessed metrics.
No UI-only invented data.

CHECKLIST

- GPU icon opens modal
- static GPU fields come from "systeminformation.graphics()"
- live fields come from real telemetry only
- unsupported metrics are not faked
- unavailable fields clearly handled
- modal is visually consistent with the app glass system

FINAL OUTPUT

Return:

1. exact static fields now shown from "systeminformation.graphics()"
2. exact live fields shown from current telemetry
3. which requested fields were not supported and therefore excluded
4. confirmation that the modal contains only real data
