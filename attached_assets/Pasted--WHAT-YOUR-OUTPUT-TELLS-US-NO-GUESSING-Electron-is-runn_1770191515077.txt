THE FIX (STRICT CHECKLIST – DO THIS IN ORDER)

STEP 1: FIX preload.ts (THIS IS MANDATORY)

Open:

electron/preload.ts

You MUST expose a heartbeat function.

Add this EXACTLY:

contextBridge.exposeInMainWorld("telemetry", {
  ping: () => ipcRenderer.invoke("telemetry:ping"),

  getLive: () => ipcRenderer.invoke("telemetry:getLive"),
  getEnhanced: () => ipcRenderer.invoke("telemetry:getEnhanced"),

  startStream: () => ipcRenderer.send("telemetry:start"),
  stopStream: () => ipcRenderer.send("telemetry:stop"),

  onUpdate: (cb: (data: any) => void) =>
    ipcRenderer.on("telemetry:update", (_, data) => cb(data)),
});

If this is not present, nothing else matters.

STEP 2: FIX main.ts IPC (YOU ARE MISSING THIS)

Open:

electron/main.ts

Add these handlers:

ipcMain.handle("telemetry:ping", () => "pong");

ipcMain.handle("telemetry:getLive", async () => {
  return await getSystemSnapshot(); // systeminformation
});

ipcMain.handle("telemetry:getEnhanced", async () => {
  return await getEnhancedSnapshot(); // LibreHardwareMonitor
});

Then add streaming:

let interval: NodeJS.Timeout | null = null;

ipcMain.on("telemetry:start", (event) => {
  if (interval) return;

  interval = setInterval(async () => {
    const data = await getMergedTelemetry();
    event.sender.send("telemetry:update", data);
  }, 5000);
});

ipcMain.on("telemetry:stop", () => {
  if (interval) {
    clearInterval(interval);
    interval = null;
  }
});

This is what your graphs and rescan NEED.
