TASK: Fix transparent/black flash on first tab open in Electron app

PROBLEM:
Each time a user opens a tab for the FIRST time:

- the app briefly disappears
- desktop wallpaper/background becomes visible
- then the tab appears
- issue only happens once per tab
- after first open, the tab is cached and no longer flashes

This strongly indicates React lazy-loading + Suspense fallback rendering null.

ROOT CAUSE:
Current code uses:

<Suspense fallback={null}>

When a lazy chunk loads:

- React temporarily renders NOTHING
- Electron compositor exposes the underlying BrowserWindow surface
- creates transparent/black flash effect

There is also a second issue:
fullscreen motion wrappers use:

initial={{ opacity: 0 }}

This makes the ENTIRE APP transparent during first route mount.

FILES TO INSPECT ONLY:

- client/src/App.tsx
- client/src/main.tsx
- client/index.html
- electron/main.js

DO NOT TOUCH:

- telemetry
- AI
- backend
- tweak systems
- systeminformation
- IPC
- auth
- logs

FIXES REQUIRED:

1. Replace ALL:

fallback={null}

WITH:

fallback={<DarkFallback />}

2. Add this component near top of App.tsx:

const DarkFallback = () => (
  <div
    style={{
      position: 'fixed',
      inset: 0,
      background: '#070b14',
      zIndex: 0
    }}
  />
)

3. Find ALL fullscreen motion wrappers using:

initial={{ opacity: 0 }}

Especially around:

- authenticated app shell
- route transitions
- AnimatePresence wrappers

Change them to:

initial={{ opacity: 1 }}

OR remove the initial opacity animation entirely.

RULE:
The ENTIRE APP SHELL must NEVER become transparent.

4. Ensure sidebar/nav/layout NEVER remounts during route changes.

Only inner route content should change.

5. Verify BrowserWindow uses:

backgroundColor: '#070b14'

6. Verify NO:

transparent: true

exists anywhere in BrowserWindow config.

7. In index.html ensure:

html, body, #root {
  background: #070b14 !important;
}

EXPECTED RESULT:

double click app
→ instant dark frame
→ intro appears immediately
→ no white flash

first tab open
→ route loads instantly
→ no transparent flash
→ no wallpaper visible
→ no fullscreen repaint
→ app shell remains solid

Do NOT add more logs.

Do NOT modify telemetry.
This is a frontend rendering/compositor issue only.
