TASK

Ensure the GPU modal always represents ONE correct GPU, with static identity and live telemetry aligned, and handle all partial-data cases cleanly.

PROBLEM

Right now there is no guarantee that:

- systeminformation.graphics() controller
- telemetry.gpu stream

refer to the same GPU.

This will break on:

- iGPU + dGPU systems
- multi-GPU desktops
- eGPU setups

This creates trust-breaking mismatches (wrong model with wrong usage).

GOAL

- One canonical GPU selection
- Static + live data aligned
- Multi-GPU safe
- No silent failures
- Clear fallback states

IMPLEMENTATION

1. Create GPU resolution logic

Add a single function that determines the active GPU.

Priority:

- match telemetry GPU to controller (by model/vendor/bus if possible)
- else prefer discrete GPU (NVIDIA/AMD over Intel)
- else highest VRAM
- else first valid controller

Do NOT let static and live resolve independently.

2. Create a stable matching key

Use:

- model (normalized)
- vendor
- bus
- vendorId/deviceId if available

Match telemetry to controller using this.

3. Bind modal to resolved GPU

Both:

- identity section
- telemetry section

must use the SAME resolved GPU.

4. Add explicit modal states

Handle:

- full data (static + live)
- static only
- live only
- no GPU data

Show a small status message instead of silently omitting everything.

5. Harden telemetry values

If values are missing:

- show fallback (e.g. "--" or "No data")
- never render broken bars or NaN

6. Improve VRAM wording

If vramDynamic is true:
label as:
"Shared / dynamic memory"
not just "VRAM"

Avoid misleading users.

7. Dev logging (important)

In development, log:

- selected GPU
- telemetry GPU
- match result (exact / fallback)

Remove or silence in production.

CHECKLIST

- GPU selection logic implemented
- static and live always aligned
- multi-GPU mismatch eliminated
- fallback states implemented
- telemetry safely handled
- VRAM labeling clarified

FINAL OUTPUT

Return:

- how GPU matching works
- fallback order
- test results on multi-GPU scenarios
