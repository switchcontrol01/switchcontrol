We are implementing a built-in RAM cleaner using a Rust helper binary (Option 3). No external downloads for users.
Goal: Add a native Windows helper sc_memory.exe built from Rust that performs safe memory trimming and returns JSON to Electron. Then wire it into SwitchControl UI with 3 modes: safe, smart, advanced.
Hard rules:
Use only documented Windows APIs.
Never touch critical/system processes.
Never kill processes.
Output JSON only via stdout.
Electron calls the binary, parses JSON, shows results with proper loading and error states.
Must not trigger tours or premium flows.
1) Create Rust helper project
Create folder: electron/native/sc_memory/
Run: cargo init --bin
Add these dependencies to electron/native/sc_memory/Cargo.toml:
windows = { version = "0.56", features = ["Win32_Foundation","Win32_System_Threading","Win32_System_ProcessStatus","Win32_System_Diagnostics_ToolHelp","Win32_System_SystemInformation"] }
serde = { version = "1", features = ["derive"] }
serde_json = "1"
2) Implement helper CLI
Binary name: sc_memory.exe
CLI: sc_memory.exe --mode safe|smart|advanced
Behavior:
Enumerate processes (Toolhelp32 snapshot).
For each process:
Skip if in denylist (see below).
Skip PID 0, 4, and any PID < 100.
Try OpenProcess with required rights.
Call K32EmptyWorkingSet(handle) to trim working set.
Measure before/after working set using GetProcessMemoryInfo.
Return JSON summary with:
mode
processes_scanned
processes_trimmed
estimated_mb_freed
top_trimmed (smart/advanced: top 5 by freed MB)
execution_ms
errors_count
Denylist (must include): system csrss.exe winlogon.exe services.exe lsass.exe dwm.exe audiodg.exe nvcontainer.exe amdow.exe easyanticheat.exe battleye.exe vgc.exe vgtray.exe epicgameslauncher.exe (optional skip) Any process name containing “anti-cheat” (case-insensitive) skip
Smart mode additional:
Only trim processes with working set >= 150 MB
Owned by current user (best-effort: if ownership check is hard, at least exclude SYSTEM via denylist and PID rules)
Advanced mode:
Same as smart but threshold 80 MB
If OpenProcess fails due to access denied, skip without crashing
Do not require admin, just do best-effort
3) Build and bundle
We need the exe to ship inside the Electron app.
Build command for Windows target: cargo build --release
Copy output exe into: electron/bin/sc_memory.exe
Add this copy step to the existing electron build pipeline so packaged builds include it.
4) Electron integration
In electron/main.ts (or main.js): Create IPC handler: memory:clean It receives mode. It spawns electron/bin/sc_memory.exe --mode <mode> Timeout 12 seconds If stdout is not valid JSON, treat as error.
In electron/preload.ts: Expose: window.electronAPI.memoryClean(mode)
5) Renderer UI
In the Clear RAM UI: Replace fake display-only behavior.
On click:
Disable buttons
Show “Optimizing memory…” loader for at least 900ms minimum (even if fast)
Call memoryClean(mode)
Show results:
“Estimated memory released: X MB”
“Processes optimized: Y”
Expandable “Details” showing top trimmed processes
If error:
Show toast “Memory clean failed” + safe message
Do not crash UI
6) Safety and UX constraints
Must not trigger any onboarding/premium flows.
Must not run automatically on startup.
Must not run more than once concurrently (lock).
Must not claim huge gains. Keep language honest.
