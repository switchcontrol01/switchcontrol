TASK
Apply the tweak safety audit fixes across SwitchControl.

PROBLEM
Some tweaks are mislabeled, unsafe, or can worsen ping/audio. Users report ping jumping from 5ms to 50ms after Safe/Moderate tweaks. Bluetooth tweak can break Bluetooth headset mic/audio in Discord and Fortnite. One network tweak is broken because apply and revert are identical.

GOAL
Make every tweak truthful, safe, reversible, and correctly classified. Remove risky or unstable tweaks from Apply Recommended.

IMPLEMENTATION

1. Update safety labels and recommended eligibility

Reclassify these:

- fax-printer
  New label: Risky
  Recommended: false
  Rename: Disable Print Spooler
  Warning: Disables the Windows Print Spooler and can break printing, PDF print-to-file, XPS, and Adobe print workflows.

- bluetooth
  New label: Moderate
  Recommended: false
  Warning: Disables Bluetooth services including BthA2dp. This can break Bluetooth headset audio and microphone in Discord, Fortnite, and Windows.

- wifi
  New label: Risky
  Recommended: false
  Add connectivity warning and pre-check. Do not apply if no active Ethernet connection exists.

- hyper-v
  New label: Risky
  Recommended: false
  Warning: Disables Hyper-V, WSL2, Docker Desktop, Android emulators, and Windows Sandbox after reboot.

- prefetch
  New label: Moderate
  Recommended: false
  Warning: Can hurt startup/app launch performance on HDD systems.

- show-file-extensions
  New label: Moderate
  Recommended: false
  Warning: Restarts Explorer, which can briefly close taskbar/desktop and Explorer windows.

- tcp-nagle
  New label: Moderate
  Recommended: false
  Warning: Can increase ping on Wi-Fi, congested networks, VPNs, or unstable connections. Best only on clean wired gigabit.

- tcp-congestion
  New label: Risky
  Recommended: false
  Warning: CTCP is throughput-focused and can hurt gaming latency.

- tcp-task-offload
  New label: Risky
  Recommended: false
  Warning: Disables NIC offloading and can increase CPU load or reduce throughput.

- tcp-winhttp
  New label: Unsupported
  Recommended: false
  Disable toggle
  Reason: Apply and revert both set autotuning to normal, so this tweak is a no-op and cannot restore the previous state safely.

- udp-offloads
  New label: Moderate
  Recommended: false
  Warning: Can increase CPU load on UDP-heavy games.

- FlowControl NIC property
  New label: Moderate
  Recommended: false
  Warning: Depends on switch/router configuration. Disabling can cause packet drops on managed switches.

3. Audio/mic protection
Add an AudioGuard rule.

Any tweak that touches:
- BthA2dp
- Audiosrv
- AudioEndpointBuilder
- microphone privacy
- Windows voice clarity
- audio enhancements
- capture devices

must be blocked from Recommended and must show a warning before apply.

Add logs:
[AudioGuard] blocked id=... reason=mic_or_voice_risk

4. Network ping protection
For network tweaks that can affect ping, add a lightweight pre/post guard.

Before apply:
- record active adapter
- record link speed
- ping default gateway 3 times if available

After apply:
- wait briefly
- ping default gateway again 3 times
- if latency jumps heavily or gateway becomes unreachable, rollback automatically

No constant ping loops.
No fake internet ping claims.
Only use this guard during apply.

Add logs:
[NetworkGuard] id=... beforePing=... afterPing=...
[NetworkGuard] rollback id=... reason=latency_worse

5. Fix tcp-winhttp
Disable tcp-winhttp completely unless proper baseline restore is implemented.

Do not keep a toggle where apply and revert are identical.

Return unsupported result:
{
  success: false,
  unsupported: true,
  failureType: "unsupported",
  userMessage: "Tweak Not Supported",
  hint: "This tweak is disabled because apply and revert were identical and could not safely restore the previous setting."
}
