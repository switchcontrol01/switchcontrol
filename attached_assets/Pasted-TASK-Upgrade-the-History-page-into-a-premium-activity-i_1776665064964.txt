TASK

Upgrade the History page into a premium activity intelligence center with graphs, filters, grouped timeline, richer event detail, and stronger analytics.

PROBLEM

The current History page is too basic for the level of the rest of SwitchControl.

Right now it is mostly just:

- a flat log list
- export JSON
- clear history
- timestamp
- page badge

That is not enough for a premium optimization app.

It needs:

- real graphs
- useful analytics
- grouped events
- search
- filters
- success vs failure visibility
- event importance
- better metadata
- session intelligence
- premium motion and layout polish

GOAL

Turn History into a real analytics and audit page that shows:

- what happened
- when it happened
- what module it belonged to
- whether it succeeded or failed
- which modules are used most
- how activity trends change over time
- which events matter most

Keep the current SwitchControl visual language:

- dark glass UI
- violet and cyan accents
- premium blur and fade motion
- animated charts
- polished desktop and mobile layout

Do not make it look like a boring admin table.

IMPLEMENTATION

1. Rebuild the History page structure into these sections:

A. Header

- title
- subtitle
- total actions badge
- export button
- clear history button

B. Summary cards
Add premium animated summary cards for:

- Total Actions
- Success Rate
- Failed Actions
- Most Used Module
- Last Active
- Recent Session Count

C. Graph area
Add rich animated charts for:

- Actions Over Time
- Success vs Failure
- Module Usage Breakdown
- Recent Activity Density or compact activity trend strip

D. Filters and search
Add:

- search box
- module filter
- result filter
- date range filter
- sort toggle

E. Grouped timeline
Replace the flat list with grouped timeline sections by date.
Examples:

- Today
- Yesterday
- Earlier This Week
- Older

Each event row should show:

- action
- module badge
- status badge
- timestamp
- impact tag
- notes preview if present

Each row should support expand/collapse for more detail.

2. Add graphs

Required graphs:

A. Actions Over Time

- line or area chart
- supports today, 7 days, 30 days, all

B. Success vs Failure

- stacked bar or area chart
- show successful vs failed events
- include warning or reverted if available

C. Module Usage Breakdown

- donut chart or animated horizontal bar chart
- modules like:
  Tweaks
  Security
  Power
  Network
  Cleaner
  Debloat
  Startup
  BIOS Advisor
  AI Advisor
  History
  other future modules

D. Recent Activity Density

- compact strip chart or mini heat style display
- shows when app activity is heavier or lighter

Charts must feel premium:

- smooth animations
- dark theme first
- soft glow
- readable labels
- no clutter

3. Add better summary intelligence

The page should calculate and show:

- total events
- number of successful events
- number of failed events
- success rate percentage
- most-used module
- least-used module if easy
- top action this week if easy
- latest major event
- latest failed event
- total sessions today if feasible
