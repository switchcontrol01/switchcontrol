TWEAK CATEGORIES
Inside Extreme Labs, group tweaks into sections:

1. Latency Core
- GlobalTimerResolutionRequests
- Timer resolution monitor/control
- Dynamic tick toggle
- TSC sync policy review
- HPET/useplatformclock review only unless explicitly supported

2. Scheduler / CPU
- Win32PrioritySeparation profiles
- SystemResponsiveness profiles
- MMCSS NoLazyMode
- Power throttling off
- Game process priority profile

3. Gaming / Capture
- Disable GameDVR
- Disable Xbox capture
- Optimizations for windowed games
- Per-game fullscreen optimization status

4. Network Latency
- NetworkThrottlingIndex
- TCPNoDelay / TcpAckFrequency
- RSS enable
- Interrupt moderation review
- EEE / Green Ethernet review
- Flow control review

5. Service Weight
Advanced review only:
- Windows Search
- SysMain
- Print Spooler
- Xbox services
- Bluetooth services
- Selected updater services

6. Startup / Vendor Weight
- Edge update services
- Adobe updater
- Teams background startup
- vendor update helpers
- unnecessary startup entries

STRICT SAFETY RULES
Even in Extreme Labs, do not add these:
- rename ctfmon.exe
- rename TextInputHost.exe
- rename backgroundTaskHost.exe
- disable PlugPlay
- disable Task Scheduler globally
- disable EventLog
- disable BFE/firewall base
- disable DHCP
- disable DNS Client
- disable NlaSvc
- disable Windows Installer
- disable UAC
- disable Defender entirely
- disable anti-cheat
- disable Discord/voice processes
- disable audio services
- disable GPU driver services globally

These are not advanced tweaks. They are system damage.
