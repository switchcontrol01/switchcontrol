STEP 2 — Centralize trigger logic
Add ONE effect:
Ts
Copy code
useEffect(() => {
  if (!user?.loggedIn) return
  if (phase !== "authenticated") return
  if (!user) return
  if (activeFlow !== "none") return

  // PRIORITY 1: First time user
  if (isFirstTimeUser()) {
    setActiveFlow("firstTime")
    return
  }

  // PRIORITY 2: Premium unlock (once per lifetime)
  if (
    user.isPremium === true &&
    user.hasSeenPremiumUnlock === false
  ) {
    setActiveFlow("premiumUnlock")
    return
  }

  // PRIORITY 3: Premium tour (once)
  if (
    user.isPremium === true &&
    !hasSeenPremiumTour()
  ) {
    setActiveFlow("premiumTour")
    return
  }

}, [
  user?.loggedIn,
  user?.isPremium,
  user?.hasSeenPremiumUnlock,
  phase,
  activeFlow
])
Do NOT depend on entire user object.
