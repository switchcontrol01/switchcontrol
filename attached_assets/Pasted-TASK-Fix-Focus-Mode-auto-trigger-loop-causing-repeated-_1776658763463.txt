TASK

Fix Focus Mode auto-trigger loop causing repeated enable/disable spam.

PROBLEM

Focus Mode is being repeatedly toggled ON automatically after user disables it.

The system continuously re-evaluates auto triggers and re-applies Focus Mode without respecting user intent.

This results in:

- Focus Mode enabling repeatedly
- user unable to disable it
- rapid state flickering
- poor UX and loss of control

ROOT CAUSE

- auto-trigger logic runs on every telemetry / hydration / state update
- no idempotency
- no cooldown
- no ownership tracking
- no protection for manual user override

GOAL

Focus Mode must:

- activate only when conditions CHANGE, not continuously
- respect manual user disable
- never re-enable itself immediately after user turns it off
- run auto triggers in a controlled, debounced way

IMPLEMENTATION

1. Add activation state guard

Before enabling Focus Mode:

if (focusModeActive) return

Prevents repeated activation spam.

---

2. Add trigger state tracking

Track last trigger condition:

focusTriggerState = {
gameDetected: boolean,
fullscreen: boolean,
lastEvaluated: timestamp
}

Only trigger when state changes from false → true

---

3. Add cooldown system

When Focus Mode is toggled (auto or manual):

set cooldown:

focusCooldownUntil = Date.now() + 10000 (10 seconds minimum)

Auto triggers must NOT run during cooldown.

---

4. Add manual override protection

When user disables Focus Mode:

focusManuallyDisabled = true
manualDisableTimestamp = Date.now()

Auto triggers must NOT re-enable it for at least:

- 30–60 seconds minimum

OR until condition changes again.

---

5. Add source tracking

Track who enabled it:

focusModeSource = "auto" | "manual"

Rules:

- if source === "manual", auto cannot override immediately
- if user disables → lock auto temporarily

---

6. Debounce trigger evaluation

Wrap auto-trigger logic:

debounce(triggerEvaluation, 1000–2000ms)

Do NOT run triggers on every telemetry tick.

---

7. Prevent hydration re-trigger

During:

- app load
- entitlement refresh
- telemetry reconnect

Do NOT auto-trigger Focus Mode.

Only allow triggers after system stabilizes.

Add:

isHydrating flag

if (isHydrating) return

---

8. Fix interval / loop spam

If using setInterval or subscriptions:

Ensure only ONE instance runs.

Logs show:
"Telemetry Manager already running"

That means duplicate loops exist.

Fix by enforcing singleton:

if (telemetryRunning) return

---

9. Add debug logs (temporary)

Log clearly:

[FocusMode] Trigger blocked: cooldown
[FocusMode] Trigger blocked: manual override
[FocusMode] Activated by auto
[FocusMode] Activated by manual

---

RESULT

- Focus Mode activates once per valid trigger
- user can disable it without it fighting back
- no flickering or spam toggling
- system behaves predictably
