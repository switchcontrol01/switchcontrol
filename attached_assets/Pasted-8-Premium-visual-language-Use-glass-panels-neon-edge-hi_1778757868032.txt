9. Performance rules

- no canvas particles unless paused when offscreen
- no constant blur repaint
- prefer transform and opacity
- count-up numbers must use requestAnimationFrame and stop when done
- pause decorative animations when document.hidden is true
- do not increase telemetry polling
- do not trigger repeated file scans during render
- scan only when user clicks Scan System
- clean only when user clicks Clean Selected
- memoize derived category totals
- avoid re-rendering every item when only summary stats change
