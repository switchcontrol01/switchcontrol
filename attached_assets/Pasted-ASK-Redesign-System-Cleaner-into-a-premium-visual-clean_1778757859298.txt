ASK
Redesign System Cleaner into a premium visual cleanup command center.

PROBLEM
Current System Cleaner feels like a long settings list. It looks bland, fake, and boring. Too much scrolling, too many clicks, weak hierarchy, no graphs, no before/after story, and no satisfying scan-to-clean flow.

GOAL
Make System Cleaner feel premium, visual, animated, and low-click:
- less scrolling
- fewer clicks
- animated scan flow
- animated clean flow
- graphs and before/after UI
- clear category structure
- real scan/clean data only
- no CPU spike garbage

IMPLEMENTATION

1. Layout redesign

Replace the list-first layout with this structure:

TOP HERO
Create CleanerHero.tsx:
- large “System Cleaner” title
- subtitle focused on real scan-based cleaning
- live scan status chip
- primary CTA: Scan System
- secondary CTA: Clean Selected
- total selected size
- last scan time
- optional “Select Recommended” button
- optional “Safe Only” toggle

The user should understand the cleaner in 3 seconds.

2. Visual dashboard row

Create CleanerStatsGrid.tsx with 4 animated cards:
- Total junk found
- Selected to clean
- Biggest category
- Estimated boot/RAM benefit

Requirements:
- values count up smoothly after scan
- cards reveal one by one
- hover lift
- neon edge glow
- no fake numbers
- use real backend scan result data

3. Center visual system

Create CleanerRadialChart.tsx:
- radial/donut cleanup chart showing category distribution:
  - temp files
  - update cache
  - crash dumps
  - browser/app cache
  - logs
  - other

Create CleanerBeforeAfter.tsx:
- before bar = total junk found
- after bar = remaining junk after selected items are cleaned
- animate bars after scan and after clean
- show “you are removing X% of found junk”

This must give visual proof, not just text.

4. Compact category accordions

Replace the huge scrolling item list with CleanerCategoryAccordion.tsx.

Categories:
- Storage Noise
- Latency Killers
- Browser/App Cache
- System Logs
- Admin Required
- Safe Only

Collapsed row must show:
- icon
- category name
- item count
- selected size
- total size
- risk badge
- select-all toggle
- expand arrow

Expanded state shows item rows.

Each item row must show:
- name
- path or description
- size
- safety/risk badge
- checkbox
- clean status

Keep collapsed rows useful so the user does not need to open every category.

5. Sticky action/summary panel

Create CleanerActionPanel.tsx:
- selected item count
- selected size
- biggest selected category
- risk summary
- recommended-clean summary
- Clean Selected button
- Scan System button when no scan exists
- filter controls:
  - All
  - Found only
  - Selected
  - Safe only
  - Admin
  - Biggest first
  - Priority

Desktop:
- sticky right panel

Mobile:
- stack under hero
- no horizontal overflow

6. Animated scan sequence

When Scan System is clicked:
- button morphs into scanning state
- page progress rail sweeps across the top section
- category cards reveal one by one
- stats count up
- chart fills segment by segment
- found categories slide in smoothly
- found rows fade/slide in only after real data arrives

Rules:
- do not add fake delays longer than 1.2s
- if backend scan is still running, keep real loading state alive
- never invent fake sizes
- no repeated scans while one scan is active

7. Animated clean sequence

Create CleanerProgressTimeline.tsx.

When Clean Selected is clicked, show timeline:
- Preparing cleanup
- Closing safe handles
- Removing selected files
- Verifying freed space
- Done

After backend clean completes:
- show “Cleaned X MB”
- before/after bars animate to final state
- cleaned rows collapse, fade, or shimmer green
- success glow pulse around summary panel
- update stats using actual clean result
- keep failed/skipped items visible with reason
