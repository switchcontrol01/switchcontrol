TASK

Re-enable DevTools everywhere in the Electron app for debugging.

Current problem:
DevTools are either disabled, restricted, or not opening reliably in some environments (dev and/or packaged builds).

I need DevTools accessible:
- in development
- in packaged builds (temporarily for debugging)
- on demand via shortcut
- on demand via code

GOAL

Make DevTools fully accessible and reliable across the entire app.

REQUIRED CHANGES

1. BrowserWindow config

Find where BrowserWindow is created (main.js or equivalent).

Ensure:

- devTools is NOT disabled
- no flags like:
  - devTools: false
  - contextIsolation misconfig blocking access (keep it enabled but correct preload)
- webPreferences must allow DevTools usage

Example requirement:
devTools must be enabled or not explicitly disabled.

2. Force DevTools open on launch (debug mode)

Add:

mainWindow.webContents.openDevTools({ mode: 'detach' });

This should run:
- in development always
- in production only if a debug flag is enabled (see step 4)

3. Global shortcut to toggle DevTools

Register a global shortcut:

Ctrl + Shift + I

Implementation:
- works in both dev and production
- toggles DevTools open/close on the focused window
- must not crash if no window is focused

4. Debug flag for production builds

Add a simple toggle so DevTools can be enabled in packaged builds when needed.

Options:
- environment variable (preferred)
- or config flag

Example behavior:
- if process.env.DEBUG_DEVTOOLS === 'true' → open DevTools on launch
- otherwise do not auto-open

5. Remove any blocking logic

Search entire codebase and REMOVE or DISABLE anything that blocks DevTools:

- webContents.closeDevTools()
- any code that prevents opening DevTools in production
- any menu removal that disables inspection (unless intentional, but shortcut must still work)
- any CSP or security config that interferes with DevTools access

6. Preload / IPC safety

Ensure preload still works correctly with DevTools open:
- no crashes when inspecting window.electronAPI
- no errors accessing context-isolated objects

7. Verification

Test both environments:

DEV MODE:
- DevTools auto-opens on launch
- Ctrl + Shift + I toggles DevTools
- no errors in console

PACKAGED BUILD:
- with debug flag ON → DevTools opens
- with debug flag OFF → DevTools can still be opened via shortcut
- no crashes or blocked access

RETURN FORMAT

Return:
1. exact files changed

3. exact shortcut implementation
4. exact debug flag implementation
5. confirmation DevTools works in dev and packaged builds
6. confirmation nothing is blocking DevTools anymore
