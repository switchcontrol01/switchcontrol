Make the SwitchControl Home page feel more alive and premium. Keep it professional, not “gamey”. Add subtle motion, depth, and micro interactions without hurting readability or performance.

Project context:
- React + Tailwind (Vite).
- Home page is likely client/src/pages/Home.tsx (or Landing.tsx / index route component).
- Use existing design system. No heavy libraries.

Required changes:

1) Animated background (hero section):
- Add a full-screen animated gradient behind the hero (slow 20-30s loop).
- Add 2 to 3 blurred glow blobs (purple, indigo, cyan) that drift slowly using CSS keyframes.
- Add a very subtle noise overlay (6-10% opacity) to remove flatness/banding.
- Background should be behind content (z-index), with a dark base so text stays readable.

2) Hero entrance animations:
- On first load, animate:
  - Headline fades in and moves up slightly (opacity 0 -> 1, translateY 12px -> 0).
  - Subheadline fades in after 120ms delay.
  - Buttons fade/scale in after 200ms delay.
- Use pure CSS animations or small utility classes, no framer-motion required.

3) CTA button micro interaction:
- Primary CTA gets a soft pulsing glow (very subtle).
- On hover: slight lift (translateY -2px), stronger glow, faster gradient shift.
- Secondary CTA: underline or border highlight on hover.

4) Stats row (the -12ms, -8ms, +15%, +22%):
- Animate the numbers counting up on page load (simple JS counter, no libraries).
- Add a shimmer/gradient sweep across the stat cards once when visible.
- Add hover: border brightens + glow increases slightly.

5) Feature cards section:
- On scroll into view, feature cards should fade up one by one (staggered).
- Add hover motion: small lift + shadow + icon glow.
- Add a thin animated border gradient that moves slowly around each card on hover only.

6) Navbar:
- Add a slight background blur when scrolling (sticky nav).
- Add active link underline animation (from center outward).

Implementation notes:
- Create a small CSS file or global styles section for keyframes:
  - gradientShift
  - blobFloat1/blobFloat2/blobFloat3
  - fadeUp
  - borderSweep (optional)
- Keep all animations subtle: duration 400-900ms for entrances, 20-30s for background loops.
- Respect reduced motion: if prefers-reduced-motion is enabled, disable animations.

Deliverable:
