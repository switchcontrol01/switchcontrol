4. Apply Recommended safety guard

Create one shared function:

isRecommendedSafe(tweakId)

Apply Recommended must only include tweaks that pass this function.

Reject:
- risky tweaks
- situational network tweaks
- audio or mic impacting tweaks
- Bluetooth
- Wi-Fi
- bcdedit tweaks
- reboot-required tweaks
- DCOM
- HDCP
- NVIDIA helper tweaks
- print spooler
- unsupported tweaks
- helper-required tweaks
- tweaks with failed verification
- tweaks with unclear revert

Apply Recommended must be boring-safe, not aggressive.
