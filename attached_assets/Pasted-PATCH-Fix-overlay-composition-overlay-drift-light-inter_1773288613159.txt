PATCH: Fix overlay composition, overlay drift/light interaction, and hero text light catch

PROBLEM

Three issues still remain:

1. The blueprint overlays are too parallel and horizontally leveled.
2. The overlays are blurred, but they do not feel alive because the drift and light interaction are too weak.
3. The hero headline still does not visibly catch the sun streak light.

This is now a composition + layering fix, not a design exploration task.

AIM

Fix the overlays so they feel intentionally placed, softly drifting, and lit by the same atmosphere.

Fix the hero text so the sun streak visibly interacts with it.

WHAT WE ARE ACHIEVING

After this patch:

- overlays will no longer sit parallel
- one overlay will sit higher, one lower, one centered faintly
- overlays will have subtle float motion
- overlays will receive visible but soft directional streak light
- hero text will visibly catch a light sheen from the sun streak
- the hero will finally feel integrated instead of layered separately

IMPLEMENTATION

STEP 1: FIX OVERLAY COMPOSITION

File:
client/src/components/website/BlueprintImageOverlay.tsx

The three overlays must not sit level with each other.

Use this layout:

LEFT OVERLAY
- top: 14%
- left: 10%
- rotate: -10deg
- translate: slight negative X and slight negative Y

CENTER OVERLAY
- top: 52%
- left: 50%
- transform: translate(-50%, -50%) scale(1.12)
- rotate: -2deg
- opacity lower than the others

RIGHT OVERLAY
- top: 36%
- right: 7%
- rotate: 7deg
- translate: slight positive X and positive Y

Important:
The right overlay must sit lower than the left overlay.
The center overlay must be the faintest.
The overlays must not look mirrored or aligned in a straight row.

STEP 2: STRENGTHEN OVERLAY FLOAT MOTION

File:
client/src/index.css

The overlay drift is too weak.

Increase overlay motion slightly, but keep it premium.

Movement targets:
- X drift: 14px to 24px
- Y drift: 10px to 18px
- scale drift: 1.00 to 1.04

Duration:
- chip: 24s to 28s
- graphs: 30s to 34s
- parts: 34s to 40s

Do not make the motion fast.
Do not pulse opacity.
Only subtle transform drift.

STEP 3: ADD SUN-LIT HAZE OVER THE OVERLAYS

File:
client/src/components/website/BlueprintImageOverlay.tsx
or WebsiteBackground.tsx if easier for stack control

Add a soft streak-lit haze layer specifically for the overlay region.

This is not a full-page streak.
This is a local blurred light pass over the blueprint overlays.

Requirements:
- diagonal
- blurred
- noticeable but soft
- lower opacity than the main sun streak
- one from upper-left
- one from lower-right

These should softly pass across the overlays so they feel lit, not pasted.

Use:
- mix-blend-mode: screen
- blur: large
- opacity around 0.08 to 0.12

STEP 4: FIX HERO TEXT LIGHT CATCH

File:
client/src/pages/Landing.tsx

The sun streak is still not visually interacting with the headline.

Add a dedicated light-catch layer to the hero text wrapper.

Correct stack order inside hero section must be:

1. WebsiteBackground
2. blueprint overlays
3. hero text light-catch overlay
4. hero headline text
5. hero mockup

The text wrapper must include an absolute sheen layer that moves with the sun streak direction.

This sheen layer should:
- be clipped to the hero text area
- use a soft diagonal white/cyan gradient
- animate slowly across the text
- remain subtle but visible

Important:
The text itself should stay readable white.
Do not make the full headline gradient transparent text.
The sheen should be an overlay interaction, not a replacement text color system.

STEP 5: ADD HERO TEXT GLOW RESPONSE

File:
client/src/index.css

Create a hero text light response class.

Behavior:
- slight text-shadow increase as sheen passes
- soft white/cyan highlight
- no harsh bloom
- no constant glowing

This must feel like the text is catching studio light, not permanently glowing.

STEP 6: VERIFY DESKTOP HERO FLOAT

File:
client/src/pages/Landing.tsx

The hero text float must apply on desktop.

Check whether the float class is attached to the actual headline wrapper.
If it is applied only to a mobile wrapper or hidden container, move it to the main desktop hero text container.

The animation must apply to:
- the main H1 block
- not the entire page
- not only one span
- not a mobile-only version

STEP 7: DO NOT CHANGE THESE

Do not:
- add more overlays
- add more blur than already exists
- add more particles
- add stronger global purple fog
- move overlays into the text itself
- make text transparent gradient again

This patch is only for:
- composition
- drift
- local light interaction
- headline light catch
