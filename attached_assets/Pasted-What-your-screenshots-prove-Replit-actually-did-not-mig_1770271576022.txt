Why your premium animation is not playing (most likely)
One of these is happening. Replit needs to confirm which with logs:
Upgrade event never detected
Your auth-store refreshEntitlements() sets upgraded = previousPlan === 'free' && newUser.plan === 'premium'
If previousPlan is already “premium” (stale store, or you refresh, or you logged out/in), upgraded becomes false and animation never triggers.
The “already shown” flag is set too early
PremiumUpgradeAnimation usually uses a “shouldShowPremiumAnimation” + “reset flag”.
If they call “markShown” on mount or on any premium check, it will never replay when the real upgrade happens.
Website flow vs Electron flow mismatch
In Electron, you need to handle: external browser payment -> deep link back to app or user manually returns -> app refreshes entitlements -> triggers animation.
If the deep link reaches renderer but the renderer never calls refreshEntitlements() in response, animation won’t trigger.
The animation exists but is not rendered
It might be behind a route, conditional, or z-index/portal issue.
Or “prefers-reduced-motion” is disabling it if you coded it that way.
Or it plays but instantly disappears because you immediately route to /home.
