TASK

Fix the landing page load-in animation so the page no longer spawns all elements at once. It needs to feel staged, premium, and fluid.

PROBLEM

Right now when entering the website, everything appears at the same time.

That looks cheap and unpolished.

The page should not feel like React finished rendering a tree.
It should feel like the experience is arriving in a controlled sequence.

Current issue:

- nav, hero text, buttons, and app mockup all spawn together
- no visual hierarchy in the entrance
- no smooth visual flow
- it feels abrupt instead of premium
- the first impression is weaker than it should be

GOAL

Make the landing page load in from top to bottom in a fluid, elegant sequence.

It must feel:

- premium
- cinematic
- smooth
- intentional
- layered
- high-end

Not laggy.
Not bouncy.
Not delayed for the sake of delay.

The motion should guide the eye naturally down the page.

IMPLEMENTATION

1. Create a staged entrance sequence

Do NOT let the whole hero appear in one frame.

Use a proper sequence such as:

Stage 1

- background glow / ambient atmosphere fades in first
- topology / environmental layers become visible first

Stage 2

- top nav and top badge fade in gently

Stage 3

- main headline fades/slides in
- subheadline follows slightly after

Stage 4

- CTA buttons fade in after the text

Stage 5

- hero app visual / product card enters last with a slightly more dramatic reveal

This should feel like the page is building itself from top to bottom.

2. Use soft fade + slight vertical motion

Use:

- opacity transition
- subtle y motion
- maybe slight blur-to-sharp cleanup if done carefully

Do NOT use:

- harsh slide-ins
- overscaled pop
- springy bounce
- gimmicky stagger
- anything that feels template-like

The effect should be elegant and restrained.

3. Make the motion timings feel premium

The timing should breathe.

Not instant.
Not sluggish.

Use overlaps so the sequence feels connected, not robotic.
Each section should begin before the prior one fully finishes.

The result should feel fluid, not step-by-step mechanical.

4. Preserve top-to-bottom visual hierarchy

The eye should read the page in this order:

- top navigation / top badge
- main headline
- support line
- CTA row
- product visual

That hierarchy must be obvious through motion alone.

5. Background should already be alive before hero content arrives

The background atmosphere should not wait for the content.
It should already be softly active, so the hero appears into a living space.

This is important.
The scene itself must exist before the content loads in.

6. Avoid spawn-in on refresh and first load

Audit what is causing the sudden spawn effect.

Potential issues to check:

- everything mounting at once with no initial states
- missing initial motion values
- parent container revealing children instantly
- hydration / layout flash
- animation conditions tied incorrectly to render state

Fix the root cause, not just visual band-aids.
