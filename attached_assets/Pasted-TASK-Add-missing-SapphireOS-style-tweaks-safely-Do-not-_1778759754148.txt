1. Add new tweaks

A. MMCSS NoLazyMode

ID: mmcss-nolazymode
Name: Disable MMCSS Lazy Mode
Category: System and Power
Risk: Moderate
Recommended: No
Admin: Yes

Registry:
HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile

Apply:
Set NoLazyMode = 1 DWORD

Revert:
Restore baseline.
If no baseline existed, remove NoLazyMode or set 0.

Check:
NoLazyMode equals 1.

Warning:
May improve responsiveness in some game/audio workloads, but can increase background scheduling pressure. Do not mark Safe.

B. SvcHostSplitThreshold

ID: svchost-split-threshold
Name: Service Host Split Threshold
Category: Advanced System
Risk: Moderate / Advanced
Recommended: No
Type: Dropdown, not toggle
Admin: Yes

Options:
Default
8GB RAM
16GB RAM
32GB RAM
64GB RAM

Registry:
HKLM\SYSTEM\CurrentControlSet\Control

Value:
SvcHostSplitThresholdInKB

Apply values:
8GB = 8388608
16GB = 16777216
32GB = 33554432
64GB = 67108864

Revert:
Restore captured baseline value.
If no baseline existed, remove SvcHostSplitThresholdInKB.

Check:
Read SvcHostSplitThresholdInKB and compare selected value.

Warning:
Controls how Windows groups services into svchost processes. More splitting can improve isolation but use more RAM. Less splitting can reduce process count but reduce isolation.

Must use existing ownership/baseline system. Do not hardcode revert.

ID: disable-hdcp
Name: Disable HDCP
Category: Display Stability
Risk: Moderate / Risky
Recommended: No
Admin: Yes if implemented

Purpose:
Can help with capture cards, OBS black screens, monitor handshake issues, or DRM-related display problems.

Warning:

Implementation rule:
Only add as supported if there is a real driver-supported method already available in the codebase.
