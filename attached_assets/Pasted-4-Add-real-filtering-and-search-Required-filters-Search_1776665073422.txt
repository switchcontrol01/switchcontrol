Module filters should support:

Each event row should support richer metadata.

Expanded row should show:

- full timestamp
- module
- result
- notes
- action subtype if available
- target if available
- impact level
- reversible true/false if available
- any extra metadata from the event if available

Make important events visually stronger than tiny informational events.

6. Add event hierarchy

Normalize each history event into a stronger UI shape.

Suggested UI status:

- success
- failed
- warning
- info
- reverted

Suggested impact:

- low
- medium
- high

Examples:

- export history = info / low
- smart scan completed = success / medium
- tweak applied = success / medium
- tweak failed = failed / high
- rollback = reverted / medium
- security issue detected = warning or failed / high

Use subtle visual hierarchy:

- colored badge
- left glow or border
- icon treatment

Do not overdo it.
