TASK
Redesign the entire Power Plan page into a premium, advanced, high-value UI without breaking existing logic.

PROBLEM
The current Power Plan page works but feels too basic. It is mostly cards and buttons. The user needs to understand what each plan changes, what Windows is currently using, what settings are active, and what performance impact each setting has.

GOAL
Make Power Plan feel like a premium performance control center:
- More visual
- More animated
- More useful
- More trustworthy
- No fake controls
- No broken existing logic

DESIGN DIRECTION
Use current SwitchControl neon glass style, but make this page more advanced:
- Vibrant gradients
- Animated power-flow lines
- SVG diagrams
- Before/after comparison panels
- Live Windows verification badges
- Rich setting breakdowns
- Graphs for latency, consistency, power saving, responsiveness

PAGE STRUCTURE

1. Hero status panel
Show:
- Active Windows power plan
- Active GUID
- Verification status
- Last applied profile
- Whether SwitchControl owns the plan
- Warning if Windows active plan differs from app state

2. Profile cards
Profiles:
- Maximum Performance
- Balanced Gaming
- Efficiency / Laptop
- Custom

Each card should show:
- Purpose
- Best for
- Tradeoffs
- Real Windows verification state
- Apply button
- Settings summary icons

3. Custom builder section
For Custom:
- Editable custom plan name
- Real-time validation
- Save/apply button
- Shows exact Windows plan name that will be created
- Shows exact GUID after creation
- Shows whether custom plan is active

4. Before/after graph section
Add premium graphs:
- CPU minimum/maximum processor state
- Core parking state
- USB/PCIe power saving state
- Sleep behavior
- Expected latency impact
- Expected battery/heat impact

These can be visual estimates, but label them clearly as estimated.

5. Configuration breakdown
Show real settings pulled from Windows:
- CPU boost
- Frequency scaling
- Min processor state
- Max processor state
- Core parking
- PCIe link state
- USB selective suspend
- Sleep
- Display sleep
- Power button behavior if available

Each item should show:
- Current value
- Desired value
- Verified or mismatch

6. Advanced controls
Keep advanced controls, but only if wired to backend.
If not wired:
- Disable them
- Show "Coming soon" or "Not connected to backend yet"

7. Logs/debug drawer
Add optional debug panel:
- Last command run
- Last verification result
- Active plan GUID
- Created custom GUIDs
- Cleanup/revert result

IMPORTANT RULES
- Do not change working power plan backend logic unless needed for custom bug
- Do not fake active states
- Do not make controls that do nothing
- Do not remove existing premium/free behavior
- Do not break free trial revert cleanup
- Do not rename app to anything except Switchcontrol

CHECKLIST
- Page still loads fast
- Existing Max Performance still applies
- Balanced Gaming still applies
- Efficiency still applies
- Custom creates real custom named plan
- Windows Power Options matches app state
- UI looks premium, not template
- No frontend-only switches
- No fake graphs without labels
- No broken revert behavior

FINAL OUTPUT
Power Plan page becomes a premium, verified power-control center with real Windows state, rich visuals, graphs, custom plan naming, and no fake frontend-only controls.
