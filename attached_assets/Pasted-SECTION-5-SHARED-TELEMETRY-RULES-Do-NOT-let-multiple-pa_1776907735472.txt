SECTION 5 — SHARED TELEMETRY RULES
Do NOT let multiple pages create their own telemetry loops for the same data.

Need:
- one shared telemetry manager for low-cost live stats if dashboard needs live feel
- consumers subscribe to shared state
- consumers do not create duplicate polling
- expensive detailed telemetry should only run when the page that needs it is active

If telemetry is already centralized, harden it:
- confirm only one active poll loop exists
- confirm hidden pages are not also polling
- confirm dashboard child components consume cache, not start their own timers

SECTION 6 — AUTH GATING
Protected route polling must never start before auth is ready.

Rules:
- no mount-time protected fetches with empty dependency arrays
- no polling when user is not logged in
- no polling while token/bootstrap state is unresolved
- no retry loops that spam 401s during startup

Add guards using the real auth source of truth:
- user?.loggedIn
- auth ready flag
- entitlements verified if needed

SECTION 7 — CACHE, DON’T RECOMPUTE
Where useful, keep short-lived cached responses instead of recomputing on every page re-entry.

Rules:
- cached data can render instantly on page open
- then refresh in background if stale
- use realistic TTLs by feature
- do not keep invalid stale auth-protected data forever
- do not trigger duplicate backend work from multiple components reading same thing

SECTION 8 — BACKEND HARDENING
Audit backend recurring work.

Need to identify:
- startup warmers
- repeated collectors
- unused recurring loops
- feature jobs that run even without a frontend consumer

Refactor so:
- backend global core stays alive
- feature-specific heavy collectors start only when requested
- repeated expensive work is cached with TTL
- no hidden feature loop runs forever without demand

Do NOT break packaged Electron boot.

SECTION 9 — CLEANUP REQUIREMENTS
For every page-scoped workload:
- clearInterval / clearTimeout on cleanup
- unsubscribe websocket listeners
- abort fetches where possible
- stop IPC subscriptions
- stop backend collectors when last subscriber leaves
- prevent state updates after unmount
