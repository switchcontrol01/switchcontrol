This log actually looks pretty healthy overall. Startup is good. Backend comes up in ~1.3s, first frame ~277 ms, dashboard ~3.9 s. Premium verification works. GPU detection works. Tweak batch takes ~2.1 s.

The big problem screaming from these logs is SysIntelligence.

### Major issue

This:

```
[SysIntelligence] phase=full start — deep collection
```

Then:

```
battery timeout
users timeout
baseboard timeout
bios timeout
graphics timeout
osInfo timeout
platformPS timeout
monitorEDID timeout
diskLayout timeout
netIf timeout
cpu timeout
```

Almost everything timed out.

Eventually:

```
phase=full complete in 6439ms

MB=null
BIOS=null
CPU=null
GPUs=0
RAMsticks=2
```

So SysIntelligence is spending 6.4 seconds trying to collect stuff and getting almost nothing.

---

# What's probably happening

Almost certainly this stuff is still being wrapped with:

```js
Promise.race([
   systeminformation.xxx(),
   timeout()
])
```

with 2-5 second limits.

But systeminformation is blocking because:

* PowerShell is being spawned repeatedly
* WMI calls are hanging
* Certain hardware queries are slow on 9800X3D systems
* monitor EDID and network connections are expensive

# CPU query timeout

This is concerning:

```
probe=cpu timeout
CPU=null
```

Yet startup already knew:

```
AMD Ryzen 7 9800X3D
```

Meaning SysIntelligence is redundantly querying CPU again.

It should just consume:

```js
cachedSpecs.cpu
```

instead of running another SI query.
