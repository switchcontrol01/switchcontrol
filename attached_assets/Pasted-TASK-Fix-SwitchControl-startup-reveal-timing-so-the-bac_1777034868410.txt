TASK
Fix SwitchControl startup reveal timing so the background, logo, text, and loading line appear together smoothly.

PROBLEM
On launch, the background renders slightly before the logo and text. This makes startup feel laggy and unpolished. The logo/text animation should not pop in late.

GOAL
Make startup feel premium:
- background, logo, title text, and loading line reveal as one coordinated sequence
- no background-only frame
- logo and text blur/fade in smoothly
- no white flash
- no delayed logo pop-in
- no startup CPU spike
- keep existing backend/startup logic intact

IMPLEMENTATION
1. Audit the splash/startup component and App.tsx launch handshake.
2. Do not show the main app window until the splash shell is visually ready.
3. Preload the app logo before sending `app:first-frame-ready`.
4. Add a splash-ready state:
   - background loaded
   - logo image decoded
   - text mounted
   - first animation frame painted
5. Use two `requestAnimationFrame()` calls after the splash DOM is mounted before sending the ready IPC.
6. Start the splash hidden with opacity 0 and slight blur.
7. Reveal the entire splash container together:
   - opacity 0 -> 1
   - blur 8px -> 0px
   - scale 0.985 -> 1
8. The background must not become visible earlier than the logo/text.
9. Avoid animating huge blur layers every frame. Animate opacity/transform only.
10. Keep the dark base background visible during loading.

FILES TO CHECK
- client/src/App.tsx
- splash/loading component
- logo component or image import
- electron/main.js first-frame-ready handling
- preload IPC bridge if used

CODE DIRECTION
Use this pattern inside the splash component:

```ts
const [ready, setReady] = useState(false);

useEffect(() => {
  let cancelled = false;

  async function prepareSplash() {
    const img = new Image();
    img.src = logoSrc;

    try {
      if ("decode" in img) await img.decode();
    } catch {}

    requestAnimationFrame(() => {
      requestAnimationFrame(() => {
        if (!cancelled) {
          setReady(true);
          window.electronAPI?.app?.firstFrameReady?.();
        }
      });
    });
  }

  prepareSplash();

  return () => {
    cancelled = true;
  };
}, []);
