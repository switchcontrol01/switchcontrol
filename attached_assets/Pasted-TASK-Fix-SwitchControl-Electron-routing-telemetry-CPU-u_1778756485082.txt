TASK
Fix SwitchControl Electron routing, telemetry CPU usage, admin detection, and tweak PowerShell safety.

PROBLEM
The app still has hidden performance and correctness issues:
1. main.js comments say GPU PowerShell does not run in the background, but pollTelemetry still calls getGpuPerfCounterLoad().
2. api.ts routes cloud-truth endpoints through the local embedded backend in packaged Electron.
3. Tweaks.tsx calls electronAPI.isAdmin(), but main.js may not register app:isAdmin.
4. tweak-executor protects queryPowerShell with a semaphore, but runPowerShell is unprotected.
5. Memory cleaner shows the wrong error when sc_memory.exe is missing in packaged installs.

GOAL
Make packaged Electron stable:
- No background PowerShell GPU polling.
- Cloud auth/premium/device/billing/admin routes always hit https://switchcontrol.org.
- Local backend only handles Windows operations, telemetry, tweaks, cleaner, focus, security, startup, debloat.
- Admin state works.
- PowerShell spawn bursts are capped.
- Missing memory helper gives a reinstall/update message.

IMPLEMENTATION

- Set TELEMETRY_BASE_MS to 4000.
- Keep TELEMETRY_SLOW_MS at 8000.
- Set GPU_COUNTER_REFRESH_TTL to 120000.
- Remove the getGpuPerfCounterLoad() call from pollTelemetry().
- pollTelemetry may update GPU VRAM using getGpuStatic(), but must not spawn PowerShell.
- telemetry:getLive must only return cached gpuPollCache values.
- telemetry:refreshGpuLoad remains the only place that calls getGpuPerfCounterLoad().
- Add ipcMain.handle('app:isAdmin') using cached checkWindowsAdmin().
- Fix any comments claiming the telemetry loop does not call GPU PowerShell so they match the code.
- Change missing sc_memory.exe message to:
  "Memory helper is missing from this installation. Please update or reinstall SwitchControl."

2. client/src/lib/api.ts
- Add CLOUD_ONLY_PREFIXES:
  /api/me
  /api/auth
  /api/premium
  /api/device
  /api/stripe
  /api/billing
  /api/admin
