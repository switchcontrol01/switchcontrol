PRIMARY PRIORITIES

The following items are mandatory and must be reviewed and implemented if safe:

1. Stop telemetry polling when nobody is connected

- Telemetry should start automatically when first websocket client connects.
- Telemetry should stop after configurable idle timeout when all clients disconnect.
- Must support Replit scale-to-zero behavior.

2. Telemetry snapshot caching

- Generate telemetry once.
- Reuse cached snapshot everywhere.
- Eliminate duplicate snapshot generation.

3. JWT verification caching

- Cache verified JWT sessions.
- Reduce database lookups.
- Support logout invalidation.
- Support entitlement changes.
- Support bans and revocation.

4. WebSocket compression

- Enable permessage-deflate.
- Optimize for low CPU overhead.

5. Remove process lists from frequent telemetry payloads

- Process data should not be sent every telemetry update.
- Process data must be fetched separately when Process Manager is open.

6. Shared WebSocket serialization

- Serialize payload once.
- Reuse serialized payload for all clients.

7. Delta broadcasts

- Skip broadcasts when data has not meaningfully changed.

8. Telemetry interval optimization

- Review polling interval.
- Reduce unnecessary updates.

9. Eliminate duplicate systeminformation calls

- Use shared cache where possible.
- Remove duplicate polling paths.

10. Hardware/specification caching

- Cache static system specs.
- Cache memory layout.
- Cache expensive WMI operations.
