TASK
Fix Debloat uninstall confirmation modal positioning.

PROBLEM
In Debloat > Uninstall section, when clicking Uninstall on an app, the confirmation popup appears around the middle of the scrollable page. The user has to manually scroll to see/use it.

GOAL
The uninstall confirmation modal must appear centered in the visible viewport immediately after clicking Uninstall, no matter where the user is scrolled.

IMPLEMENTATION
1. Find the uninstall confirmation component/modal in the Debloat page.

Likely files:
- Debloat.tsx
- UninstallApps.tsx
- AppUninstaller.tsx
- ConfirmUninstallModal.tsx
- modal/dialog component used by uninstall flow

2. Move the modal out of the scrollable list/container.

Use a portal:

ReactDOM.createPortal(
  <ConfirmUninstallModal ... />,
  document.body
)

3. Modal wrapper must use fixed viewport positioning:

className:
fixed inset-0 z-[9999] flex items-center justify-center

4. Overlay should cover viewport, not parent container:

className:
fixed inset-0 bg-black/60 backdrop-blur-sm

5. Modal card:

className:
relative w-full max-w-md rounded-2xl border border-white/10 bg-[#0B0D14]/95 shadow-2xl

6. Prevent background scroll while modal is open:

useEffect(() => {
  if (!isOpen) return;
  const previous = document.body.style.overflow;
  document.body.style.overflow = "hidden";
  return () => {
    document.body.style.overflow = previous;
  };
}, [isOpen]);

7. Keyboard behavior:
- Escape closes modal
- Enter confirms only if focused inside modal or confirm button active
- Focus confirm/cancel buttons when opened

8. Do not auto-scroll the page to the modal.
The modal should float above the page.

9. Add logs:
[Debloat] uninstall confirm opened appName=... source=...
[Debloat] uninstall confirm closed
[Debloat] uninstall confirmed appName=...

CHECKLIST
- Click uninstall at top of list: modal appears centered in visible screen.
- Click uninstall halfway down list: modal appears centered in visible screen.
- Click uninstall near bottom: modal appears centered in visible screen.
- No manual scrolling needed.
- Background list does not scroll while modal is open.
- Escape closes modal.
- Cancel closes modal.
- Confirm still runs the same uninstall logic.
