## Biggest issue #1: SysIntelligence is completely broken

This is the worst thing in the log.

Everything times out:

* battery
* users
* baseboard
* BIOS
* graphics
* OS
* platformPS
* memory layout
* disk layout
* network
* CPU

Eventually:

```
[SysIntelligence] phase=full complete in 6530ms | MB=null | BIOS=null | CPU=null | GPUs=0 | RAMsticks=0
```

and

```
returned all-null
```

So System Intelligence is spending 6.5 seconds doing work and getting nothing.

### Why?

Very likely:

* Too many simultaneous `systeminformation` calls.
* WMI spawning is hanging.
* Promise timeout wrappers are too aggressive.
* You're trying to collect everything in parallel.

I would not run 15+ probes at startup.

Move these into:

* motherboard → lazy load
* BIOS → lazy load
* RAM layout → lazy load
* processes → lazy load
* network connections → lazy load

Dashboard startup should not depend on any of these.
