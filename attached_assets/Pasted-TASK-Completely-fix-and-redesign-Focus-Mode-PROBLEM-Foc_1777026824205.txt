TASK
Completely fix and redesign Focus Mode.

PROBLEM
Focus Mode currently feels unfinished:
- UI is bland and basic.
- Profiles are just simple cards with toggles.
- There are no graphs, visuals, before/after explanations, or premium-feeling interactions.
- Auto Triggers appear clickable but are only frontend. They do not actually do anything.
- It feels like a fake section instead of a real system feature.

GOAL
Make Focus Mode one of the best free sections in SwitchControl. It must feel premium, useful, and real, while staying lightweight with no heavy polling.

IMPLEMENTATION

1. Backend truth first
Audit every Focus Mode action:
- Mute notifications
- Kill overlays
- Suppress background apps
- Network priority flag
- High performance mode
- Win key lockdown
- Game launch trigger
- Fullscreen app trigger
- Controller connected trigger
- Headset connected trigger
- Scheduled time trigger
- Monitor disarmed

For each item:
- If backend exists, wire the toggle to real backend execution.
- If backend does not exist, do not leave it as fake.
- Either implement it properly or mark it as “Coming soon” and disable the toggle.

2. Auto Triggers must not be fake
Create a real Focus Mode trigger system.

Minimum real triggers:
- Manual activate button
- Scheduled time trigger
- Game launch trigger using detected process names from App Booster installed games
- Fullscreen app trigger using active window/fullscreen detection if available

Optional triggers:
- Controller connected
- Headset connected

If optional triggers are too unreliable, disable them and label as “Coming soon”.

3. No heavy polling
Do not add expensive background polling.
Use:
- existing telemetry loop where possible
- lightweight interval only when Focus Mode triggers are enabled
- process checks no faster than every 5 to 10 seconds
- pause checks when Focus Mode triggers are disabled
- pause checks when app is closed/minimized unless trigger monitoring is explicitly enabled

4. Persistent Focus Mode state
When Focus Mode is activated:
- save active profile
- save enabled actions
- save session duration
- save trigger source
- persist state across route changes
- restore/revert correctly on expiry or manual stop

5. Revert must be bulletproof
Every action needs:
- apply()
- verify()
- revert()
- status()

When Focus Mode ends, all reversible changes must be restored:
- power plan restored
- notification state restored
- overlays restored if changed
- Win key restored
- network priority removed if applied

6. UI redesign
Redesign Focus Mode to feel elite.

Add:
- premium hero panel with animated “focus shield” visual
- live session timeline
- before/after impact cards
- “distractions blocked” visual counter
- system load strip showing CPU, RAM, process count
- profile comparison cards
- animated flow: Trigger → Actions → System State → Revert
- better action cards with icons, status, risk level, and explanation
- session duration ring or graph
- Focus Mode history card
- clean empty states
- micro animations on apply, stop, and revert

7. Profiles
Profiles should feel different:
Gaming Focus:
- highest performance
- overlays killed
- notifications muted
- background apps suppressed
- network priority enabled

Work / Study:
- notifications muted
- distractions blocked
- optional background app suppression
- no aggressive gaming tweaks by default

Streaming:
- do not kill streaming tools
- keep audio devices safe
- mute notifications
- avoid breaking OBS/Discord

Competitive:
- most aggressive safe profile
- show warning for anything that may affect usability

8. Button behavior
Main button should clearly show:
- Activate Focus Mode
- Applying...
- Active
- Stop Focus Mode
- Reverting...
- Reverted

No silent toggles.
No fake success states.

9. Validation
Add debug logs:
[FocusMode] profile selected
[FocusMode] action apply started
[FocusMode] action verified
[FocusMode] trigger enabled
[FocusMode] trigger fired
[FocusMode] revert complete

CHECKLIST
- No fake toggles.
- Auto triggers either work or are disabled as Coming Soon.
- Focus Mode applies real changes.
- Focus Mode reverts real changes.
- No excessive polling.
- UI feels premium and information-rich.
- Free section feels valuable, not cheap.
