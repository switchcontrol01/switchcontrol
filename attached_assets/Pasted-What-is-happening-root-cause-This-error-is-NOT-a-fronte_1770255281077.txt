What is happening (root cause)

This error is NOT a frontend bug.

> “This file does not have an app associated with it for performing this action”



That error appears when Windows tries to open a URL that should be handled by a custom protocol, but no protocol handler is registered.

What your flow currently is

1. Electron app opens


2. User clicks “Login with Google”


3. Electron opens browser to:

https://switchcontrol.org/auth/google?source=electron


4. Google login succeeds


5. Your backend redirects to something like:

switchcontrol://auth?token=...


6. Windows does not know what switchcontrol:// is


7. Login fails



So the UI renders, auth starts, but the deep-link return is broken.


---

Why this works on web but not Electron

On web:

OAuth redirects back to https://switchcontrol.org/...

Browser handles it normally


On Electron:

OAuth must return to your desktop app

That requires a custom protocol registration

Right now: ❌ not registered



---

This is the exact missing piece

You have:

preload listeners

renderer listeners

backend generating deep links


But you do not have:

> app.setAsDefaultProtocolClient("switchcontrol")



So Windows has no idea what to do with switchcontrol://.


---

What needs to be fixed (non-negotiable)

1. Register protocol in electron/main.js

Tell Replit to add exactly this:

app.setAsDefaultProtocolClient("switchcontrol");

This must be:

At top-level (before whenReady)

And again inside whenReady for safety


Example:

app.setAsDefaultProtocolClient("switchcontrol");

app.whenReady().then(() => {
  app.setAsDefaultProtocolClient("switchcontrol");
  createWindow();
});


---

2. Handle deep-link events (Windows-specific)

Tell Replit to add:

app.on("open-url", (event, url) => {
  event.preventDefault();
  if (mainWindow) {
    mainWindow.webContents.send("auth:callback", url);
  }
});

AND for Windows launch:

const gotTheLock = app.requestSingleInstanceLock();

if (!gotTheLock) {
  app.quit();
} else {
  app.on("second-instance", (event, commandLine) => {
    const url = commandLine.find(arg => arg.startsWith("switchcontrol://"));
    if (url && mainWindow) {
      mainWindow.webContents.send("auth:callback", url);
    }
  });
}

This is required on Windows. macOS uses open-url, Windows uses second-instance.


---

3. Ensure backend redirects to protocol only for Electron

Your backend must do something like:

if (source === "electron") {
  redirect(`switchcontrol://auth?token=${token}`);
} else {
  redirect(`https://switchcontrol.org/auth/success`);
}

From your logs, you are already doing this, so backend is fine.
