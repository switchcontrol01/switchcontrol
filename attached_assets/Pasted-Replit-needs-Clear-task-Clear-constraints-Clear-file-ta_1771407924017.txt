1️⃣ Main Process

Ensure systeminformation is installed.

Add IPC handler:

ipcMain.handle("telemetry:getGpu", async () => {
  const si = require("systeminformation");
  const g = await si.graphics();
  if (!g.controllers.length) return null;

  const c = g.controllers[0];

  return {
    model: c.model,
    driverVersion: c.driverVersion,
    vram: c.vram,
    memoryUsed: c.memoryUsed,
    load: c.utilizationGpu ?? c.load,
    temperature: c.temperatureGpu,
    powerDraw: c.powerDraw,
    clockCore: c.clockCore,
    clockMemory: c.clockMemory
  };
});

No transformations.
