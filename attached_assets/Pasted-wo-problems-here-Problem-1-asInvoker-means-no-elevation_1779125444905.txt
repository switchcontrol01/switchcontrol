Problem 1: asInvoker means no elevation

requestedExecutionLevel: "asInvoker" means the app runs at whatever privilege level the user launched it with. On most Windows setups that's a standard user account. When your tweak executor calls PowerShell with registry writes or netsh, it fails silently because it never had admin rights to begin with. This is the root cause of Extreme Labs not working and power plans not applying.

Change it to requireAdministrator:

"win": {
  "target": "nsis",
  "icon": "dist/app-icon.ico",
  "requestedExecutionLevel": "requireAdministrator"
}

This makes Windows prompt for UAC on launch. The app runs elevated for its entire session. No more per-command elevation attempts, no more silent failures.

Problem 2: No publish config means updater crashes

Without a publish block, electron-updater does not know where to look for latest.yml. It throws a 404 and crashes the update check. Add this at the top level:

"publish": {
  "provider": "generic",
  "url": "https://pub-c4010f9528c14cbd9848f2c9c7c2306d.r2.dev/"
}

One thing to verify after rebuilding: the electron/bin directory must contain sc_memory.exe and it must be committed to the repo. The extraResources block copies it into the packaged app correctly, but if the file is not in the source tree it will not be there to copy.
