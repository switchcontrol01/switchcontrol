4. Apply Recommended safety rule

Apply Recommended must include ONLY low-risk, reversible, verified tweaks.

Add guard:

isRecommendedSafe(tweakId)

It must reject:
- Risky tweaks
- Moderate network tweaks
- audio/mic-impact tweaks
- unsupported tweaks
- hidden advanced tweaks
- reboot-required tweaks
- helper-required tweaks
- WiFi/Bluetooth toggles
- bcdedit tweaks
- DCOM
- HDCP
- NVIDIA profile tweaks
- print spooler
- any tweak with known ping risk

No exceptions unless the user manually selects it.

---

5. Hardware gating

NVIDIA tweaks:
- detect NVIDIA GPU first
- if no NVIDIA GPU, show Unsupported
- do not show Apply button

DCOM:
- show only in Advanced section
- require confirmation modal

WiFi:
- detect active Ethernet before allowing disable
- if no active Ethernet, block with:
"Cannot disable Wi-Fi because no active Ethernet connection was detected."

Bluetooth:
- warn if Bluetooth audio devices are present if detectable
- otherwise show permanent warning text

---

6. UI requirements

Each new tweak must show:
- Real or Unsupported badge
- Risk badge
- Admin badge if HKLM
- clear warning box in modal
- verification status
- exact setting path in advanced details
- plain-English impact

Do not make these look like random switches.

---

7. Backend requirements

Every tweak must include:
- apply
- revert
- check
- ownership baseline capture
- post-apply verification
- clear failure result if unsupported
- no fake success

If helper is missing:
Return unsupported, not success.

---

8. Test checklist

Test:
- apply and revert each new registry tweak
- reboot persistence where required
- unsupported NVIDIA tweak on AMD machine
- WiFi block when no Ethernet exists
- Bluetooth warning visible
- Apply Recommended does not include risky/network/audio tweaks
- tcp-winhttp no longer appears as a working tweak
- no microphone, Discord, or Fortnite voice settings are touched
- no ping-risk tweak is labeled Safe

FINAL OUTPUT

Return:
- changed files
- new tweak IDs
- reclassified tweak IDs
- unsafe tweaks blocked
- helper-dependent unsupported tweaks
- test results
