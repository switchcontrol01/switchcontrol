TASK: Move basic/common tweaks to Free tier while keeping truly advanced/risky systems Premium

PROBLEM:
Current premium gating makes nearly every Advanced or Experimental tweak premium by default. This makes Premium feel like basic registry tweaks are locked, which weakens trust. Basic/common tweaks should be Free. Premium should be reserved for advanced verified systems, automation, restore-protected sessions, hardware-specific tuning, and high-risk labs.

GOAL:
Update "@shared/tweak-tiers" so common/basic tweaks are Free, while risky/hardware-specific/high-impact tweaks stay Premium.

FILES TO READ FIRST:

- "shared/tweak-tiers.ts"
- "client/src/lib/tweak-registry.ts"
- "client/src/components/tweaks/TweakCard.tsx"
- "client/src/hooks/use-tweak-executor.ts"
- any file that calls "isPremiumTweakById", "getTweakTierById", or reads "tweak.premium"

IMPLEMENTATION:

1. Keep this rule:
   Recommended tweaks are Free by default.

2. Stop treating every Advanced tweak as Premium by default.
   Change the gating logic so Premium is controlled mainly by explicit premium IDs, not broad Advanced level gating.

Current bad logic:

- Advanced = Premium
- Experimental = Premium
- Network category = Premium

Replace with:

- Recommended = Free
- Advanced = Free unless explicitly listed as premium
- Experimental = Premium unless explicitly listed as free
- Network category should NOT automatically mean Premium
