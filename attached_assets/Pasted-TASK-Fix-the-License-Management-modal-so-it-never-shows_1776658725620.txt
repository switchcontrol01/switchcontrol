TASK

Fix the License Management modal so it never shows stale premium status when opening.

PROBLEM

The License Management modal currently renders from "premiumGraceStore" immediately on open:

- "grace.getStatus(isBackendReachable)"
- "grace.plan"
- "grace.lastVerifiedAt"

Then it runs "safeRefreshEntitlements()" afterward and updates the store later.

This causes a stale-state flash:
a free user can briefly see Premium Active or Premium Lifetime before the refresh completes and corrects the UI.

GOAL

The modal must not trust stale "premiumGraceStore" data on first render.

When the modal opens:

- enter a strict loading state immediately
- refresh entitlement truth immediately
- only render Premium / Free after the refresh resolves
- never show Premium from stale grace-store data before verification completes

IMPLEMENTATION

1. Identify the stale render path

In "LicenseManagementModal", the current render path uses:

- "verificationStatus = grace.getStatus(isBackendReachable)"
- "grace.plan"
- "grace.lastVerifiedAt"

before the open-triggered "safeRefreshEntitlements()" finishes.

That is the root cause.

2. Add modal-local verification state

Inside the modal, add dedicated modal-local state such as:

const [licenseLoading, setLicenseLoading] = useState(false);
const [verifiedLicense, setVerifiedLicense] = useState<{
  status: "active" | "grace" | "expired" | "free" | "unknown";
  plan: string | null;
  isPremium: boolean;
  lastVerifiedAt: number | null;
} | null>(null);

Do not let the modal’s main display depend directly on stale grace-store values during the open sequence.

3. Force strict loading on open

When "open" becomes true:

- immediately set "licenseLoading = true"
- immediately clear previous modal-local verified state if needed
- do not render premium/free plan yet
- call "safeRefreshEntitlements()"
- after the result returns, update both:
  - modal-local verified state
  - grace store
- then set "licenseLoading = false"

4. Hard render rule

While "licenseLoading === true":

- always show neutral loading UI
- never show Premium Lifetime
- never show Active
- never show Free
- never show stale grace status

The modal should show something like:

- Verifying license...
- skeleton / neutral placeholder

5. Build final modal display from verified modal-local state

After refresh completes, render the status block from "verifiedLicense", not directly from stale grace-store state.

Only use grace-store as a persistence/cache layer, not as immediate truth on modal open.

6. Keep offline grace behavior intact

If offline:

- do not fake premium from old stale state unless it is truly valid offline grace data
- if using offline grace intentionally, render it only from verified stored grace records that are still within the allowed grace window
- do not show Premium Lifetime for a free user just because old data exists in store
