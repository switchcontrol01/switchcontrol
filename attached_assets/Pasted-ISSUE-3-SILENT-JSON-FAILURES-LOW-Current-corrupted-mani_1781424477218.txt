FILE:
deviceBindingMigration.ts

==================================================
ISSUE [MEDIUM]

Migration loop lacks per-query error handling.

- partially migrate schema
- silently stop later migrations
- leave inconsistent DB state

==================================================
FIX

Wrap every migration query:

for (const sql of migrations) {
try {
await pool.query(sql);

err.message,
"\nSQL:",
sql.slice(0, 120)
);

}
}
