TASK: Fix Premium Trial Auto Revert for Advanced Slider Tweaks

PROBLEM

When a user's Premium trial expires, standard toggle tweaks usually revert correctly, but many Premium slider and preset tweaks do not.

This is most noticeable with Advanced slider tweaks.

Examples include:

• MMCSS Background Reservation
• System Timer Resolution
• Max Pending DPC Queue Depth
• IRQ Priority Profile
• NTFS I/O Optimization Profile
• GPU Driver Timeout Profile
• Network Throttling Index
• Any Premium slider, preset or segmented tweak

Current behaviour:

• Trial expires.
• Some tweaks revert.
• Many slider tweaks remain visually applied.
• Some Windows values remain modified.
• Sometimes only a few revert after restarting the app or ending the process.
• Frontend and backend become out of sync.
• Cached state may still report Premium values.

This is a critical trial cleanup bug.

------------------------------------------------------------

GOAL

When a Premium trial expires, EVERY Premium tweak must automatically revert to its Windows default.

This includes:

• Toggle tweaks
• Slider tweaks
• Segmented sliders
• Preset profiles
• Advanced tuning sliders
• Network sliders
• NIC tuning sliders
• Extreme Labs sliders

The frontend, backend and Windows state must always match.

------------------------------------------------------------

IMPLEMENTATION

Create one unified Premium cleanup pipeline.

When Premium expires:

1. Lock Premium entitlement.
2. Find every applied Premium tweak.
3. Include ALL slider and preset tweaks.
4. Execute each tweak's revert command.
5. Verify the Windows value was restored.
6. Clear all cached frontend state.
7. Refresh every page.
8. Update duplicate tweak cards.
9. Record cleanup in History.

Do not rely on cached UI state.

Always verify the actual Windows configuration.

------------------------------------------------------------

REQUIRED TWEAK METADATA

Every Premium slider must define:

• tweakId
• canonicalId
• defaultValue
• currentValue
• premiumRequired
• applyCommand
• revertCommand
• verifyCommand
• restartRequired
• trialRevertSupported

If trialRevertSupported is missing, treat it as a bug.

------------------------------------------------------------

FRONTEND

After Premium expires:

• Clear all persisted Premium slider values.
• Clear Zustand/local cache.
• Re-fetch entitlement.
• Re-fetch live tweak states from backend.
• Refresh every duplicate tweak card.
• Reset sliders to verified Windows defaults.
• Do not require restarting the application.

------------------------------------------------------------

BACKEND

The backend must:

• Revert every Premium tweak.
• Include sliders and presets.
• Verify every revert succeeded.
• Return success/failure for each tweak.
• Never report success until Windows confirms the value has actually changed.

------------------------------------------------------------

DUPLICATE TWEAK SUPPORT

Many tweaks appear in multiple places.

Examples:

• Tweaks
• Network Tweaks
• NIC Tuning
• Extreme Labs
• AI Advisor
• Apply Recommended

These all use the same underlying Windows setting.

When one reverts, every duplicate instance must immediately update.

No duplicate card should ever display an incorrect state.

------------------------------------------------------------

VERIFY USING WINDOWS

Never trust cached frontend values.

Verify using:

• Registry
• PowerShell
• BCDEdit
• NIC Advanced Properties
• Services

Windows is always the source of truth.

------------------------------------------------------------

TESTING

Verify the following:

• Apply multiple Premium slider tweaks.
• Expire the Premium trial.
• Confirm every slider returns to Windows defaults.
• Confirm every toggle returns to default.
• Confirm duplicate tweak cards update everywhere.
• Confirm History logs the cleanup.
• Confirm restarting the app still shows default values.
• Confirm no stale cache remains.
• Confirm backend and frontend remain synchronized.

------------------------------------------------------------

FINAL OUTPUT

Premium trial expiration must completely clean up every Premium tweak, including all advanced slider and preset tweaks.

Windows state, backend state, frontend state and cached state must always remain synchronized, with no manual restart or task kill required.
