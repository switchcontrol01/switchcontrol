PHASE 5 — Scroll Blur Reveal That Actually Works

Your blur likely didn’t work because:

• IntersectionObserver threshold wrong
• CSS not using filter
• Mobile disables blur
• reveal class never applied

Here’s what should exist:

[data-reveal] {
  opacity: 0;
  transform: translateY(40px);
  filter: blur(12px);
  transition:
    opacity 0.6s ease,
    transform 0.6s ease,
    filter 0.6s ease;
}

[data-reveal].visible {
  opacity: 1;
  transform: translateY(0);
  filter: blur(0);
}

And JS:

const observer = new IntersectionObserver(
  entries => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        entry.target.classList.add("visible");
      }
    });
  },
  { threshold: 0.2 }
);

document.querySelectorAll("[data-reveal]").forEach(el => observer.observe(el));

If Replit didn’t implement blur, they probably only animated opacity.
