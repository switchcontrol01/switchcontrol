TASK

Fix the login → welcome transition so it becomes one continuous cinematic flow.

PROBLEM

Right now the experience is broken visually.

What happens:

- login screen fades/blurs out, which is good
- then the app hard-cuts straight into the welcome animation, which is bad

That instant cut kills the premium feel.

Replit has said this was fixed multiple times, but it clearly is not fixed.

GOAL

Make the sequence feel like one uninterrupted transition:

1. login UI begins exiting
2. it smoothly blurs and fades away
3. the background and overlay continue the motion
4. the welcome card fades and blurs in
5. the welcome animation begins after the new scene is already visually present

No hard cut.
No instant swap.
No rushed timing.
No separate disconnected animations.

It must feel fluid, slower, smoother, more premium, and deliberate.

IMPLEMENTATION

1. Remove the hard scene swap between login success and welcome state

Audit the exact success path after login finishes.

Find where the app is currently doing a direct state flip or route swap that causes:

- old screen disappears
- new screen appears instantly

That hard mount/unmount behavior is the bug.

The welcome scene must not appear as an instant replacement.
It must enter through a shared transition layer.

2. Build a true staged transition sequence

Use a controlled multi-phase transition such as:

- phase 1: login success confirmed
- phase 2: login scene enters exiting state
- phase 3: shared overlay / blur veil carries transition
- phase 4: welcome scene mounts invisibly or semi-hidden
- phase 5: welcome scene fades/blurs in
- phase 6: welcome card content animates in
- phase 7: logo pulse / particles / text accent animate after scene settle

Important:
Do not start the welcome card at full opacity.
Do not mount it in a visually finished state.

3. Add overlap between exit and enter

The current problem feels like:

- exit finishes
- cut
- enter starts

That is wrong.

Instead:

- login should still be fading out while the welcome layer starts softly appearing underneath or above via a transition veil
- there should be slight overlap so the handoff feels continuous

The user should never perceive an empty dead frame or a hard replacement.

4. Use blur + opacity + scale consistently

For the welcome scene:

- start slightly blurred
- start slightly dimmed
- start slightly scaled down or softened
- fade to sharp full-opacity state over time

Suggested direction:

- initial blur: subtle to moderate
- initial opacity: low, not zero snap
- initial scale: 0.97 to 0.985 range
- transition duration: longer than current, around premium pace
- easing: smooth, not snappy

For the login exit:

- let it soften and drift out
- do not collapse instantly
- no aggressive pop-out

5. Delay the inner welcome animation until the container is already visible

The welcome scene should not do this:

- mount
- immediately start flashy logo/text animation

That feels cheap.

Instead:

- first bring in the welcome container itself
- once the container is visually established
- then trigger inner content animation

Sequence:

- scene in
- card in
- text in
- accent glow / particles / badge / progress line in

6. Add a transition veil between states

Add a temporary shared transition layer that exists during the handoff only.

This can be:

- soft bloom veil
- glass blur wash
- purple/cyan atmospheric haze
- radial glow with fade
- subtle particle carry-over

This layer should bridge login and welcome so the user feels motion continuity.

Without this bridge, it will keep feeling like two separate pages.
