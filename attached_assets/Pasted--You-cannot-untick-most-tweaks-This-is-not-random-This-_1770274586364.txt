 You cannot untick most tweaks

This is not random. This is almost always caused by one of these three bugs:

Root cause A: One-way tweak state

Most likely:

applyTweak() exists

revertTweak() either does not exist or is not wired

UI toggle is bound to isApplied === true with no inverse path


So once applied, the toggle becomes visually disabled or ignores clicks.

Root cause B: UI state ≠ system state

They are probably:

Writing registry / system change

Updating UI state optimistically

Never re-querying actual system state on toggle off


So untick does nothing because the UI does not know how to “undo”.

Root cause C: Shared tweak ID collisions

You already hinted at this.
Multiple tweaks target the same registry key or command, but:

Same tweakId

Or different IDs, same underlying effect


Result:

One toggle controls multiple tweaks

Others appear locked


What must be done (non-negotiable)

Every tweak must have:

apply()

revert()

check() (authoritative system state check)


UI toggle logic must be:

onToggle:
  if off -> call revert()
  if on -> call apply()
after:
  call check()
  update UI from check(), not from local state

If Replit didn’t implement revert() for most tweaks, they are broken by design.
