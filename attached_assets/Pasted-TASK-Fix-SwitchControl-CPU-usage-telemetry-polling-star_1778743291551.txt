TASK
Fix SwitchControl CPU usage, telemetry polling, startup smoothness, memory cleaner packaging, and LiveGraph render errors without breaking existing telemetry.

PROBLEM
Latest logs show repeated PowerShell GPU counter calls:
[PS] start file=main.js fn=getGpuPerfCounterLoad reason=gpu-counter
This happens almost every telemetry poll and takes about 1.5s each time.
That is causing high CPU usage and app stutter.

Also found:
1. LiveGraph throws: <circle> attribute r: Expected length, "undefined".
2. Memory cleaner fails because sc_memory.exe is missing from resources/bin.
3. Startup still shows background before logo/text, making launch feel unsmooth.

GOAL
Lower idle CPU usage as much as possible.
Stop repeated PowerShell GPU polling.
Keep GPU telemetry working through cached data, LHM if available, and manual refresh only.
Fix LiveGraph render error.
Package memory helper correctly.
Make startup logo/text/background fade in together.

IMPLEMENTATION

1. main.js GPU polling fix
Search for any call to getGpuPerfCounterLoad inside pollTelemetry, _telemetryLoop, startTelemetryPolling, or recurring telemetry paths.

Remove getGpuPerfCounterLoad from all background loops.

It must only run inside:
ipcMain.handle('telemetry:refreshGpuLoad', ...)

Also make startup prewarm optional and run only once after UI is visible, not during launch. Prefer disabling it completely for lowest CPU.

Set:
const GPU_COUNTER_REFRESH_TTL = 120000;

In telemetry:getLive, return cached GPU values only.
Never spawn PowerShell from getLive or pollTelemetry.

2. Fix psLimiter abuse
pollTelemetry currently uses psLimiter even when it does not run PowerShell. Do not wrap normal telemetry polling in psLimiter.
Only wrap actual PowerShell functions:
- getGpuPerfCounterLoad
- tweak executions
- admin checks
- scripts

This prevents misleading [PS] logs and avoids blocking normal telemetry.

3. LHM usage
Do not remove LibreHardwareMonitor support completely.
Use it only if already running.
Never start it.
Poll LHM every 10 to 15 seconds max.
If LHM is not available, cache false for 60 seconds and do not keep checking every few seconds.

Set:
const LHM_POLL_TTL_MS = 15000;
const LHM_CHECK_INTERVAL = 60000;

4. Telemetry interval
Change normal telemetry base from 2000ms to 3000ms or 4000ms.
Keep graph UI at 2s if needed, but it should read cached values, not force expensive collection.

Use:
const TELEMETRY_BASE_MS = 4000;
const TELEMETRY_SLOW_MS = 8000;

5. SysIntelligence startup
Logs show:
[SysIntelligence] Collecting full system profile…
Collection takes 3776ms during startup.

Move this to after dashboard is shown and stable.
Delay by 5 to 8 seconds after app:window-shown.
Do not block first render, splash, dashboard, or telemetry startup.

6. LiveGraph circle error
Fix any custom dot function that returns circle with undefined cx/cy/r.
In LiveGraph, before rendering a custom circle, guard:

if (
  typeof props.cx !== "number" ||
  typeof props.cy !== "number" ||
  !Number.isFinite(props.cx) ||
  !Number.isFinite(props.cy)
) return <g key={props.key} />;

Always set r={4}. Never pass undefined.

Apply to all custom dot renderers for CPU, RAM, GPU.

7. Memory cleaner packaging
Memory cleaner fails:
C:\Program Files\SwitchControl\resources\bin\sc_memory.exe not found

Fix electron-builder packaging so sc_memory.exe is copied to:
resources/bin/sc_memory.exe

Check electron/package.json or electron-builder config.
Add something like:

extraResources:
[
  {
    "from": "electron/bin/sc_memory.exe",
    "to": "bin/sc_memory.exe"
  }
]

Also add a build-time check that fails the build if sc_memory.exe is missing.

8. Startup smoothness
Currently background appears before logo/text.
Make splash shell atomic:
- preload dark background
- preload logo image using HTMLImageElement.decode()
- do not show window until logo is decoded and first splash frame is painted
- reveal background, logo, title, and line in the same animation group
- use opacity + blur + transform only
- do not animate layout properties
- do not start backend-heavy tasks before first visual reveal

The background, logo, title, and line should fade/blur in together, not background first.

CHECKLIST
- No repeated getGpuPerfCounterLoad logs during idle.
- In 60 seconds idle, PowerShell calls should be 0 unless user manually refreshes GPU.
- CPU usage should drop significantly at idle.
- LiveGraph has no circle r undefined errors.
- Memory cleaner finds sc_memory.exe in packaged build.
- Startup shows splash elements together smoothly.
- Dashboard still receives CPU/RAM/GPU cached telemetry.
- LHM support remains but does not poll aggressively.
