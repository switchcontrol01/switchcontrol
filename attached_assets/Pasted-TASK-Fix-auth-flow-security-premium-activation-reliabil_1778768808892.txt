Harden payment/auth flow, ensure premium always activates reliably, and remove exploit paths while keeping UX smooth.

4) RATE LIMIT AUTH EXCHANGE (SECURITY)

Add at top of file:

const _exchangeAttempts = new Map();

In /api/auth/exchange:

ADD before logic:

const ip = req.ip || 'unknown';
const now = Date.now();
const record = _exchangeAttempts.get(ip);

if (record && now < record.resetAt) {
if (record.count >= 10) {
return res.status(429).json({ success: false, error: 'Too many attempts' });
}
record.count++;
} else {
_exchangeAttempts.set(ip, { count: 1, resetAt: now + 60000 });
}
