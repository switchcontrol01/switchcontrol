STEP 4 — Your routing IS WRONG for Electron (this is very likely)
You are using hash routing, but your app boot logic still assumes /.
Your App.tsx must start at #/, not /.
Your BootGate redirect must use:
Copy code
Ts
window.location.hash = '#/login';
// or
window.location.hash = '#/dashboard';
❌ NOT:
Copy code
Ts
window.location.href = '/login';
If any of your redirects use /login instead of #/login, Electron will show a blank page.
This is the #1 Electron + Vite blank-screen cause.
STEP 5 — Logo missing = wrong asset path (separate but related)
In Electron production:
Copy code
Tsx

❌ often fails
Use this instead:
Copy code
Tsx
<img src="./logo.png" />
Why:
Electron loads from file://
/logo.png points to root of disk, not app
This will not crash, but it confirms your paths are wrong.
