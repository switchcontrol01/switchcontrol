I want to build an app called SwitchControl.

SwitchControl is a polished, modern UI-first gaming optimization dashboard inspired by tools like VTRL. This version is a WEB APP PROTOTYPE only. It must NOT make real Windows system changes. All optimization actions are simulated and logged for UI and flow purposes.

Tech stack:
- Web app
- React or Next.js
- TypeScript
- Tailwind CSS
- Local state + localStorage (no database yet)

Design:
- Dark theme
- Purple / pink accent colors
- Clean, modern, gamer aesthetic
- Rounded cards, soft shadows
- Desktop-first layout

Layout:
- Fixed left sidebar navigation
- Main content area on the right

Sidebar items:
- Home (Dashboard)
- Tweaks
- Power Plan
- App Booster
- Focus Mode
- Network Tweaks
- Network Scripts
- Cleaner
- Debloat
- Startup
- Settings

Dashboard (Home):
- Greeting text: “Good afternoon, SwitchTech 👑”
- Section title: “Activity Monitor”

Dashboard cards:
1) Memory card
   - Show used RAM vs total RAM (example: 9.5 GB / 32 GB)
   - Progress bar
   - Button: “Clear RAM”
   - Clicking Clear RAM simulates freeing memory (reduce used RAM slightly but never below 3 GB)
   - Log the action to Scan History

2) CPU card
   - Show CPU name (mock, example: Ryzen 7 9800X3D)
   - Show cores and threads

3) GPU card
   - Show GPU name (mock, example: RX 7800 XT)
   - Show VRAM usage (mock)

4) Disk card
   - Local Disk (C:)
   - Used vs total storage (mock)

Account Status card:
- Shows Free or Premium
- Shows license status (mock)

App Booster card:
- Text: “No games running”

  - Title

Debloat page:

Network Tweaks page:
- Toggle-based options (simulated)

- No real network edits

Settings page:
- Theme toggle (Dark / Light)
- Toggles:
  - Enable App Booster
  - Show real-time metrics
  - Pause metrics when minimized
- Buttons:
  - Reset app data

Global behavior:
- Maintain a Scan History log for all actions
- Store history and account tier in localStorage

Output:
