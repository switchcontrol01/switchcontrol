- diskPercent: null

That means LiveGraph hides those lines correctly because the backend payload is empty.

Current architectural bugs:

1. Home.tsx tracks selectedDiskIndex, but does not pass the selected disk into LiveGraph or DiskTelemetryModal.
2. DiskTelemetryModal hardcodes primary disk:
   const primary = raw.disks.find((d) => d.mount === 'C:' || d.mount === '/') || raw.disks[0]
   so it ignores user disk selection.
3. LiveGraph only consumes live.diskPercent, but telemetry:getLive has no concept of selected disk.
4. telemetry:getGpu currently returns only raw systeminformation controller data, which is too weak and does not match what GpuModal expects.
5. Current GPU helper path is NVIDIA-centric. My machine is AMD RX 7800 XT. Do not build a solution that only works on NVIDIA.
6. Network should return 0 when idle, not null, otherwise the lines disappear.
7. Disk percent should also be a real number for the selected drive, not null.
