TASK
Perform a full performance stabilization pass across the Electron + React app. Eliminate hidden CPU usage, UI lag, micro stutter, and render inefficiencies without breaking functionality.

PROBLEM
The app already fixed major issues (PowerShell spam, duplicate telemetry), but still has hidden lag sources:
- unnecessary React re-renders
- chart rendering overhead
- animation stacking
- event listener leaks
- ResizeObserver loops
- disk scan spikes
- async task overload
- GC spikes from telemetry arrays

These cause subtle stutter and inconsistent smoothness, especially on mid-range systems.

GOAL
Make the app feel:
- fluid
- stable
- consistent FPS
- zero micro stutter

WITHOUT:
- removing core features
- faking data
- adding artificial delays

---

IMPLEMENTATION

1. TELEMETRY RENDER CONTROL

Problem:
Telemetry updates trigger too many React re-renders.

Fix:
- Split telemetry state into slices (cpu, ram, disk, gpu)
- Only update slices when values actually change
- Use shallow compare (zustand or equivalent)
- Memo all stat components (React.memo)

Hard rule:
No component should re-render if its displayed value did not change.

---

2. GRAPH PERFORMANCE HARDENING

Problem:
Charts re-render too often and handle too many data points.

Fix:
- Cap history length to max 60–100 points
- Do not recreate arrays each tick
- Reuse buffers
- Memo graph components
- Disable built-in chart animations

AnimatedLiveGraph:
- must only re-render on real data change
- skeleton must not use chart library

---

3. RESIZE OBSERVER LOOP PROTECTION

Problem:
ResizeObserver can cause layout thrashing.

Fix:
- Debounce ResizeObserver (50–100ms)
- Do NOT set state directly inside observer
- Cache width/height before applying

---

4. EVENT LISTENER CLEANUP

Problem:
Listeners accumulate over time.

Fix:
Audit and fix ALL:
- window listeners
- IPC listeners
- socket listeners

Rule:
Every addEventListener must have cleanup in useEffect return.

No duplicates allowed.

---

5. ANIMATION LIMITER SYSTEM

Problem:
Too many animations stack and cause lag.

Fix:
Create global animation guard:

- disable non-essential animations when:
  document.hidden === true
- reduce animation density under load (optional flag)
- no infinite loops
- no idle animations unless very low cost

Rule:
Animations only run on:
- scan
- clean
- apply tweak
- route change

---

6. BLUR / GLASS PERFORMANCE FIX

Problem:
Backdrop blur is expensive.

Fix:
- Remove blur from large containers
- Do not animate blur
- Limit blur to small elements only

---

7. CLEANER SCAN BATCHING

Problem:
File scanning can spike disk and freeze UI.

Fix:
- Batch directory scanning
- yield between batches (setTimeout 0 or similar)
- limit concurrency (2–4 max)

---

8. ASYNC TASK QUEUE

Problem:
Too many parallel async tasks.

Fix:
- Implement global task queue
- Max concurrency: 2–4
- Queue all:
  - scans
  - tweak checks
  - background tasks
