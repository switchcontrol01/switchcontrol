CRITICAL FIX AREAS (FROM AUDIT)

1. TELEMETRY POLLING DUPLICATION (HIGH PRIORITY)

Problem:

telemetryManager already polls IPC

LiveGraph ALSO polls getLive()

duplicate IPC traffic + rerenders


Fix:

REMOVE LiveGraph polling entirely in Electron mode

LiveGraph must subscribe to telemetry store only

telemetryManager is single source of truth



---

2. SYNC DISK I/O BLOCKING (HIGH PRIORITY)

Problem: ownership-store.js:

loadOwnership() runs fs.readFileSync every operation

saveOwnership() runs fs.writeFileSync per tweak


tweak-executor.js:

saveState called after every tweak apply

causes repeated disk writes


Fix:

batch ownership-store operations

load ONCE per batch operation

write ONCE at end

same for tweak-executor syncAll operations


DO NOT change logic, only batching


---

3. GLASSPANEL LAYOUT THRASH (HIGH PRIORITY)

Problem: GlassPanel uses:

getBoundingClientRect on mousemove


Fix:

cache bounding rect on mouseenter

update via ResizeObserver

remove per-mousemove layout reads



---

4. IPC RACE CONDITION (HIGH PRIORITY)

Problem: telemetryManager:

_ipcPollTick can run concurrently with refreshNow()


Fix:

add _ipcPollInFlight guard

prevent overlapping getLive IPC calls



---

5. POWERPLAN / LOCALSTORAGE DIVERGENCE (MEDIUM)

Problem:

localStorage stores UI state

electron store stores system state

possible desync


Fix:

ensure GUID/state persistence is unified via electronAPI layer OR

mirror state consistently via IPC


NO redesign


---

6. SVG RADAR CHART COLLISION (MEDIUM)

Problem:

gradient IDs collide across instances


Fix:

append useId() to gradient id

ensure uniqueness per instance



---

7. BACKGROUND ANIMATION GPU LOAD (HIGH PRIORITY)

Problem: animated backgrounds use:

background gradients animation


Fix:

remove background animation

replace with:

opacity animation OR

transform animation only



DO NOT animate:

background

blur

gradients

8. STARTUP TELEMETRY / SPLASH LOAD (HIGH PRIORITY)

Fix:

move telemetryManager.start()

ensure it only starts AFTER authenticated phase

remove Splash.tsx direct start calls
