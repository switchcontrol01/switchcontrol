SYSTEM PERFORMANCE REFACTOR TASK

Goal:
Make SwitchControl feel instant on startup.

Current issue:
SysIntelligence performs massive hardware enumeration during application boot causing:

- delayed dashboard hydration
- delayed telemetry visibility
- late RAM updates
- delayed card rendering
- perceived lag

Backend logs show:

- full intelligence scan = 6539ms
- multiple 4-8 second timeout operations
- blocking startup pipeline

Required architecture change:

========================
PHASE 1: FAST BOOT

During app startup ONLY collect:

- CPU model
- total RAM
- primary GPU name
- Windows version

Hard timeout:
800ms max total.

If any call exceeds timeout:
return partial data immediately.

DO NOT block app render.

Dashboard must mount immediately.

========================
PHASE 2: DEFERRED INTELLIGENCE

After dashboard visible:
wait 2500ms idle time.

Then asynchronously begin deep collection:

- disk layout
- filesystem sizes
- network connections
- monitor EDID
- BIOS
- motherboard
- battery
- process inventory
- memory layout
- platform PowerShell checks

These must:

- run independently
- never block UI
- never block telemetry
- never block cards
- update progressively

========================
PHASE 3: PARALLELIZATION

Current issue:
SysIntelligence appears serialized.

Refactor:
Run all heavy probes in Promise.allSettled batches.

Example:

Batch 1:

- bios
- baseboard
- battery

Batch 2:

- graphics
- memLayout
- diskLayout

Batch 3:

- netConn
- processes
- platformPS

No sequential waiting.

========================
PHASE 4: CACHING

Persist stable hardware info to disk cache.

Cache:

- motherboard
- BIOS
- monitor EDID
- RAM layout
- disk layout

Refresh only:

- once every 24h
  OR
- manual refresh

Do NOT recollect every app boot.

========================
PHASE 5: DASHBOARD FEEL

Dashboard requirements:

- RAM card visible instantly
- CPU telemetry visible instantly
- GPU telemetry visible instantly
- no skeleton longer than 600ms
- cards progressively hydrate
- no delayed fade-ins waiting on backend scans

========================
SUCCESS CONDITION

Target:

- visible window under 1 second
- dashboard interactive under 1.5 seconds
- telemetry visible immediately
- deep intelligence progressively streams in later

This is a startup architecture refactor, not a visual redesign.
