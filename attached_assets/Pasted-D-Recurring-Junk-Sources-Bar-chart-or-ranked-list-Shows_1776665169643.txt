3. Add cleaner priority scoring

Each cleaner item must get a priority signal.

Suggested labels:

- Clean Now
- Good Opportunity
- Minor
- Rebuilds Quickly
- Not Worth It Yet

Use a rule-based scoring model only.
Do not invent fake intelligence.

Base score on:

- current found size
- file count
- category
- risk level
- whether it rebuilds automatically
- whether it affects latency perception
- whether it is negligible

Example:

- huge temp cache = Clean Now
- tiny DNS cache = Minor
- shader cache = Rebuilds Quickly
- dead startup entries = Good Opportunity
