5. Harden IPC boundary

Audit electron/preload.js and use-updater.ts.

Rules

Renderer should only be able to call:

getState

check

download

install

onEvent


Nothing else.

In preload

expose only those minimal updater APIs

validate that these methods call defined IPC channels only

do not expose raw Electron APIs unnecessarily


In main

validate calls before executing

ignore invalid calls in impossible states


Examples:

do not allow downloadUpdate() unless current state is available

do not allow quitAndInstall() unless current state is downloaded


Return safe no-op or structured failure response instead of doing dumb things.
