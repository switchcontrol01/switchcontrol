IMPORTANT OPTIMIZATION PHILOSOPHY

Some optimizations can LOWER average FPS while significantly IMPROVING:

- frametime consistency
- input responsiveness
- latency stability
- smoothness
- stutter reduction
- 1% lows

The app must understand that:

HIGHER FPS does NOT always mean BETTER experience.

Many generic “optimizer” apps incorrectly:

- disable large numbers of services
- force aggressive timer resolutions
- break scheduler behavior
- increase DPC latency
- create thermal instability
- increase CPU overhead
- destabilize frametimes
- apply outdated Windows tweaks blindly

This can produce:

- slightly higher average FPS
  BUT:
- worse frametimes
- more stutter
- inconsistent latency
- unstable responsiveness
- worse real-world feel

SwitchControl should prioritize:

- frametime stability
- responsiveness
- low latency
- smoothness
- scheduler safety
- thermal stability
- consistent system behavior

The app should avoid:
aggressive placebo tweaks or unsafe “FPS boosting” behavior.

Optimization decisions should be:

- telemetry-aware
- hardware-aware
- scheduler-aware
- benchmark-aware
- stability-aware

The goal is:
a system that FEELS smoother and more responsive,
not simply a system showing artificially higher FPS numbers.
