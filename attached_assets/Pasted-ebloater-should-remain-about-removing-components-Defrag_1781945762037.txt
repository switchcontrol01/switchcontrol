That's much more premium and logical.Yes. Easily. You don't need some special Node package.

Windows already exposes this functionality.

Option 1 (Best)

PowerShell:

Optimize-Volume -DriveLetter C -ReTrim

For SSDs.

For HDDs:

Optimize-Volume -DriveLetter D -Defrag

Can be called from Electron:

exec(
'PowerShell -Command "Optimize-Volume -DriveLetter C -ReTrim"'
)


---

Option 2

Use:

Get-Volume
Get-PhysicalDisk

or systeminformation:

si.diskLayout()
si.fsSize()

to determine:

SSD or HDD

Capacity

Free space

Model

Interface


Then automatically choose:

SSD → ReTrim

HDD → Defrag



---

Option 3

Use Microsoft's defrag executable directly:

defrag C: /L

(/L = retrim SSD)

defrag D: /O

(/O = optimize)

No Node package required.
