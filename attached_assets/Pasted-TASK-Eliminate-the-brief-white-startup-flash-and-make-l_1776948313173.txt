TASK
Eliminate the brief white startup flash and make launch visually airtight.

PROBLEM
The app still briefly flashes white for about 0.1 to 0.2 seconds on startup.
This is not a blur issue.
It is a first-paint / launch-handshake gap.

ROOT CAUSE ANALYSIS
Based on current code:

1. preload exposes `onWindowShown`, but renderer never consumes it
2. first visible document paint is not hard-locked to dark background at the raw HTML level
3. multiple `Suspense fallback={null}` paths allow empty frames
4. authenticated phase has no persistent dark background safety layer

GOAL
From process launch to first interactive frame:
- no white frame
- no blank frame
- no empty suspense gap
- no reveal before dark UI is ready

REQUIRED FIXES

1. HARD-LOCK FIRST PAINT IN `index.html`
In the raw HTML document itself, before React mounts:
- set `html`, `body`, and `#root` background to `#07090D`
- set width/height to 100%
- remove all default margins
- set overflow hidden if needed
- optionally set `document.documentElement.style.background = '#07090D'` inline

This must exist before bundled CSS loads.

2. USE THE EXISTING `app:window-shown` HANDSHAKE
In renderer startup:
- subscribe to `window.electronAPI.onWindowShown(...)`
- only perform final opacity reveal after this event
- do not rely on implicit timing

3. REPLACE ALL `Suspense fallback={null}`
Use a real dark fallback shell, not null.
For Electron routes use a fullscreen dark loading shell.
Never allow routed content to suspend into empty nothing.

4. ADD A PERSISTENT DARK BACKGROUND FOR AUTHENTICATED PHASE TOO
Just like boot/login/welcome have a stable dark background layer,
authenticated phase must also always have a hard dark background behind route content.
This prevents any white/empty underlying frame if route tree or page hydration stalls.

5. ENSURE `#root`, `.app-root`, `.app-content` ARE ALL FULL HEIGHT
Audit CSS to ensure:
- html, body, #root = 100%
- app-root = 100%
- app-content = 100%
- background is dark at every level

6. DO NOT ALLOW EMPTY APP FRAME DURING ROUTE MOUNT
If `phase === authenticated` and routes are still settling,
show a branded dark shell instead of blank content.

FILES TO CHECK
- index.html
- client/src/main.tsx
- client/src/App.tsx
- client/src/index.css
- any AppLayout root wrappers
- any global CSS affecting html/body/#root

CODE CHANGES EXPECTED

A. In `index.html` head, add an inline style block like:
- html, body, #root { margin:0; width:100%; height:100%; background:#07090D; }

B. In `main.tsx`
- register `electronAPI.onWindowShown`
- set `document.documentElement.style.opacity = '1'` only after the app window is confirmed shown
- keep website mode immediate reveal only for non-Electron

C. In `App.tsx`
- replace `Suspense fallback={null}` with a dark branded loading shell
- add persistent authenticated background safety layer

SUCCESS CRITERIA
- no white flash on cold launch
- no white flash on relaunch
- no empty frame between splash and booting
- no empty frame between booting and authenticated
- launch is visually continuous and dark the entire time
