PHASE 1 — CORE STARTUP OPTIMIZATION (HIGHEST PRIORITY)

GOAL:
Make SwitchControl feel instant.

TARGET:
Double click app → dark shell appears instantly → telemetry hydrates progressively.

---

1. SPLIT THE GIANT JS BUNDLE

---

Current problem:
Main bundle is ~2.4MB.

This blocks:

- JS parse
- module evaluation
- React hydration
- first interaction

IMPLEMENT:

Lazy load:

- AiAdvisor
- BiosAdvisor
- Admin
- WeatherWidget
- onboarding
- charts
- recommendation engines
- premium systems
- guided tours

Use:
React.lazy()
Suspense

RULE:
Nothing nonessential should exist in first paint.

---

2. BUILD A TRUE CORE SHELL

---

FIRST PAINT SHOULD ONLY CONTAIN:

- sidebar
- top navigation
- cpu card
- gpu card
- ram card
- shell background

NOT:

- AI
- weather
- graphs
- onboarding
- recommendations
- analytics
- premium
- telemetry history

Everything else loads AFTER shell render.

---

3. REMOVE ALL STARTUP BLUR FILTERS

---

REMOVE:

- filter: blur()
- backdrop-filter

Especially:

- during startup
- during transitions
- during dashboard reveal

REPLACE WITH:

- opacity
- translateY
- scale
- gradients
- noise overlays

Blur is one of the biggest Electron GPU killers.

---

4. REMOVE ANIMATION CHAINS

---

BAD:
splash → logo → fade → dashboard → cards → blur

GOOD:
instant shell → progressive hydration

RULE:
UI responsiveness > cinematic feel

---

5. STOP BLOCKING FIRST PAINT

---

DELAY:

- weather
- AI
- recommendations
- profile fetches
- onboarding
- cloud sync
- analytics

USING:
requestIdleCallback()
or setTimeout()

ONLY AFTER shell render.

---

6. REDUCE TELEMETRY UPDATE FREQUENCY

---

CURRENT ISSUE:
Telemetry likely rerenders too aggressively.

TARGET UPDATE RATES:

CPU:
500ms

RAM:
1000ms

Temps:
1500ms

Disk:
2000ms

Weather:
15 minutes

This massively reduces React pressure.

---

7. MEMOIZE EVERYTHING HEAVY

---

USE:

- React.memo
- useMemo
- useCallback

ON:

- cards
- sidebar
- weather
- telemetry panels
- charts
- topbar

Prevent global rerenders.

---

8. NEVER MOUNT HIDDEN PAGES

---

BAD:
<AiAdvisor hidden />

GOOD:
{page === 'ai' && <AiAdvisor />}

Unmount pages completely.

---
