TASK
Fix the AI Advisor so it stops blurting out too much information at once and becomes a controlled, guided, premium diagnosis experience.

GOAL
Right now the AI Advisor is still dumping too much information too quickly.
Even if the analysis is correct, the experience feels weaker because the advisor blurts information out instead of guiding the user through it.

I want the AI Advisor to feel:
- controlled
- premium
- concise
- diagnostic
- guided
- structured
- high-trust
- product-grade

CRITICAL
Do NOT solve this with frontend-only masking.
Do NOT just visually hide a long blob of text.
Do NOT leave the backend generating uncontrolled long responses.
Do NOT let the model freestyle long paragraphs.
The fix must happen at BOTH backend and frontend level.

IMPORTANT
We are NOT redesigning the dashboard.
We are fixing the AI Advisor behavior and presentation within the existing product direction.

PROBLEM
Current likely issues:
- AI returns too much text at once
- responses are too paragraph-heavy
- output lacks strict hierarchy
- it feels like a generic chatbot response instead of a system diagnosis
- frontend reveals too much too fast
- the advisor does not feel guided or premium

We need to stop the “information blurt” problem at the source.

IMPLEMENTATION

1. AUDIT CURRENT AI ADVISOR FLOW
Audit the current AI Advisor end-to-end:
- prompt construction
- backend response handling
- output parsing
- response schema
- streaming / reveal logic
- frontend rendering
- any typing or staged presentation behavior
- fallback behavior when model output is malformed

Determine exactly why the AI still blurts information out.

2. FORCE A STRICT STRUCTURED RESPONSE SCHEMA
Do NOT allow freeform paragraph output.

The backend must enforce a structured response format similar to:

- problem
- cause
- impact
- fix
- confidence

Each field must be short and controlled.

Requirements:
- max 1 sentence per field
- concise wording
- no giant paragraph blobs
- no repeated phrasing
- no generic fluff

If the model returns invalid or oversized output:
- reject it
- re-request or repair it
- do not pass the raw blob through to frontend

3. BACKEND OUTPUT VALIDATION
Add backend validation before any AI result is sent to the frontend.

Validate:
- required fields present
- sentence length limits respected
- no oversized paragraphs
- confidence included
- no duplicated fields
- no broken JSON / malformed structure
- no overlong freeform explanation

If output fails validation:
- retry generation with stricter correction
or
- repair the structure safely
but do NOT dump raw output into UI

4. CHANGE AI TONE FROM “EXPLAINING” TO “DIAGNOSING”
The AI should stop sounding like a generic assistant giving broad advice.

It should sound like a system diagnosis engine.

Desired style:
- short
- assertive
- specific
- technical but readable
- high signal
- low fluff

Bad style:
- broad explanations
- rambling
- “you may be experiencing...”
- generic optimization language

Good style:
- “Background services are interrupting game threads”
- “Memory pressure is not the current bottleneck”
- “CPU scheduling instability is the likely cause”

5. STAGED REVEAL UI
Do NOT show everything at once.

Implement a staged reveal flow in the AI Advisor UI:

Stage 1:
- show only the main problem
- show confidence
- keep this compact and clear

Stage 2:
- reveal cause
- reveal impact

Stage 3:
- reveal fix
- reveal related action / apply suggestion if relevant

The advisor should feel like it is guiding the user, not dumping on them.

6. ONE ISSUE AT A TIME MODE
The AI Advisor should prioritize one issue at a time instead of overwhelming the user with everything at once.

Requirements:
- surface the most important current issue first
- allow moving to next issue only after the current one is understood or dismissed
- keep the experience focused

This should feel like guided optimization, not a chaotic wall of system analysis.

7. HARD LENGTH LIMITS
Enforce strict brevity rules in both backend prompt and backend validator.

Need limits such as:
- problem: short single sentence
- cause: short single sentence
- impact: short single sentence
- fix: short single sentence
- confidence: simple enum or short label

Do not allow the model to drift into essay mode.

8. FRONTEND PRESENTATION FIXES
Update the AI Advisor UI so it supports the new structured/staged behavior cleanly.

Need:
- compact initial card state
- clear main problem emphasis
- confidence displayed cleanly
- smooth staged reveal transitions
- no text wall
- no sudden giant content jump
- no clumsy layout expansion

Do NOT redesign the whole dashboard.
Only improve the AI Advisor interaction and rendering quality.

9. MICRO-ANIMATIONS / PREMIUM FEEL
The staged reveal should feel premium.

Need:
- subtle reveal transitions
- smooth expand/collapse
- controlled typing or progressive text appearance ONLY if tasteful
- no excessive slow typewriter effect
- no cheap chat-bot feel
- no jarring card resize

The AI Advisor should feel like a premium diagnostic system.
