TASK

Remove the fake/pre-seeded game list from App Booster and change the feature so it only shows games actually detected on the user’s system.

PROBLEM

App Booster is currently showing games that are not installed on the PC.

That is wrong.

The feature should not show a generic preloaded list of popular games.
It should scan the user’s actual system, detect real installed games, and only show those results.

Right now this makes App Booster look fake and untrustworthy.

GOAL

Make App Booster a real system-driven feature.

Expected behavior:

- scan the PC
- detect installed games from real launcher/install sources
- show only games actually found
- no fake default titles
- no hardcoded popular-game list pretending to be the user’s library

REMOVE THIS BEHAVIOR

- remove any default seeded game list
- remove any fallback list of popular games being shown as if detected
- remove any UI that implies a game is installed when it is not
- remove any demo catalog from the main detected library view

If you want to keep a supported-games catalog, it must be clearly separated and labeled as:

- Supported Titles
  or
- Available Profiles
  and NOT shown as detected installs

REQUIRED BEHAVIOR

1. REAL SYSTEM SCAN ONLY
   App Booster must scan real system sources such as:

- Steam libraries
- Epic Games install locations
- Riot client/game installs
- EA app locations
- Battle.net if supported
- common launcher metadata and real install paths
- safe Windows registry/start menu/uninstall references only if useful and accurate

2. DETECTED GAMES VIEW
   The main game library list must show only:

- actually installed games detected on this PC

3. EMPTY STATE
   If no supported installed games are found, show a clean honest state:

- “No supported installed games found”
- optional retry scan button
- optional manual add fallback only if truly needed

Do NOT fill the list with fake titles.

4. SUPPORTED TITLES SEPARATION
   If SwitchControl has a supported-game profile database, that is fine, but it must be shown separately as:

- Supported Games
- Available Profiles
- Compatibility Catalog

It must NOT be mixed into the detected installed game library.

5. COUNTS MUST BE REAL
   These counters must be truthful:

- Supported Games
- Detected Installs
- Profiles Active

Do not inflate them with catalog entries.
Detected installs must only count real installed games found on the machine.

6. LOGGING
   Add logs for:

- [AppBooster] scan started
- [AppBooster] launcher found/not found
- [AppBooster] installed game detected: <name>
- [AppBooster] installed game count = X
- [AppBooster] supported catalog count = X
- [AppBooster] no supported installed games found

7. UI CLARITY
   Make the interface clearly distinguish:

- installed and detected on this PC
  vs
- supported by SwitchControl in general

No misleading wording.

8. PACKAGED APP TESTING
   Test this in the actual packaged Electron app, not just dev preview.

CHECKLIST

- fake preloaded game list removed
- main game library only shows actually installed detected games
- detected install count is real
- if none found, empty state is honest and clean
- supported titles, if kept, are clearly separated from detected installs
- no misleading UI remains

FINAL OUTPUT REQUIRED

Return:

- root cause of fake game list behavior
- files changed
- where pre-seeded game data was removed
- how real detection now works
- confirmation that only installed detected games are shown in the main library
